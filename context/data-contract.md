## 一、核心策略

### 1.1 分时转日线优先
**执行时机**：每日15:00收盘后立即执行

**数据源优先级**：
1. **分时数据15:00** - 主数据源（取累计值）
   - open = 09:30第一笔
   - close = 15:00最后一笔
   - high = max(全天分时)
   - low = min(全天分时)
   - volume = 15:00累计值（不sum）
   - amount = 15:00累计值（不sum）

2. **东财日线接口** - 补充数据源（每小时尝试覆盖）
   - 尝试时间：16:00、17:00、18:00、19:00、20:00、21:00
   - 仅请求缺失日期
   - 成功则覆盖分时数据

3. **兜底机制**：东财失败时使用分时数据

**昨收价处理**：
- 分时接口获取 prevClose
- 如缺失，用昨日close字段

### 1.2 请求频次控制
| 时间 | 操作 |
|------|------|
| 15:00 | 立即执行分时转日线 |
| 16:00-21:00 | 每小时尝试东财接口覆盖缺失日期 |
| 21:00后 | 停止请求，使用分时数据兜底 |

## 四、数据更新策略

### 4.1 更新时间表
| 数据类型 | 更新时间 | 频率 | 数据源 |
|---------|---------|------|--------|
| ETF分时 | 盘中30秒 | 实时 | 东财分时接口 |
| ETF日线 | 15:00+每小时 | 1次/小时 | 分时→东财fallback |
| 指数日线 | 15:00后 | 1次/天 | 东财日线 |
| 期货分时 | 盘中 | 实时 | 新浪分时 |
| 市场成交额 | 15:00后 | 1次/天 | 东财 |

### 4.2 增量请求策略
**东财接口**：
- 仅请求缺失日期（对比已有数据）
- 起始日期：最新数据日期 + 1天
- 终止日期：最新交易日

**示例**：
```python
last_date = "2026-03-18"
start_date = "2026-03-19"
end_date = get_latest_trading_day()  # "2026-03-19"
_fetch_akshare_sina_etf("sh512480", start_date=start_date, end_date=end_date)
```

## 五、接口容错机制

### 5.1 东财接口失败处理
```python
def fetch_etf_daily_with_fallback(etf_code):
    # 1. 尝试东财日线
    daily_data = fetch_eastmoney_daily(etf_code)

    if not daily_data:
        # 2. 降级到分时转日线
        print(f"⚠️ 东财接口失败，使用分时数据兜底: {etf_code}")
        daily_data = convert_minute_to_daily(etf_code)

    return daily_data
```

### 5.2 分时数据缺失处理
- 缺失早盘：用09:31第一笔代替
- 缺失尾盘：用14:58最后一笔代替
- 中间缺失：forward fill 填充

## 六、数据质量验证

### 6.1 字段完整性检查
```python
def validate_etf_data(data):
    errors = []

    # 必需字段
    required_fields = ['date', 'open', 'close', 'high', 'low', 'amount']
    for field in required_fields:
        if field not in data:
            errors.append(f"缺失字段: {field}")

    # 数值合理性
    if data['close'] <= 0:
        errors.append("收盘价异常")

    if data['amount'] <= 0:
        errors.append("成交额异常")

    return errors
```

### 6.2 日期连续性检查
```python
def check_date_continuity(dates):
    # 检查交易日是否连续
    # 允许周末、节假日缺失
    trading_days = get_trading_days_between(dates[0], dates[-1])
    missing = set(trading_days) - set(dates)
    return missing
```

## 八、特殊场景处理

### 8.1 节假日
- 分时转日线：节前最后一天执行
- 东财接口：节假日期间不请求
- 数据标记：使用最新交易日日期

### 8.2 突发停牌
- ETF停牌：使用前一交易日数据
- 标记状态：data['status'] = 'suspended'

### 8.3 数据回补
- 检测缺失：对比交易日历
- 自动回补：使用分时数据
- 手动补齐：您手动提供数据时，直接覆盖
