# 天时风险规则发现

> 以下规则来自 2024-09 ~ 2026-07 天时回测中发现的统计规律。
> 每条规则标注: 发现日期、验证样本量、触发条件、历史表现。

---

## 规则1: 年月日三层克伐

**发现**: 年月日三层天干中，≥2层克日干(日柱天干)时，该指数大概率下跌。

**案例**:
```
创业丙寅(火): 乙(木)年 + 壬(水)月 + 丙(火)日 → -0.66%
  年乙木生火(✓), 月壬水克火(✗), 日丙火被克(✗)
  → 克伐层数=2 → 触发规则
```

**适用**: 所有4个指数。当 年干克日干 + 月干克日干 或 月干克日干 + 地支冲日支时触发。

**待验证**: 样本量尚小(每组合n=1~2)，需要更多数据确认阈值。

---

## 规则2: 满月日对特定日柱的影响

**发现**: 满月日(农历十五前后)对己卯日柱有显著负面影响。

**案例**:
```
创业己卯(土): 
  2025-01-10 丁丑月满月: -1.76%
  2025-07-09 癸未月满月: +0.16% (勉强正)
  2025-11-06 丙戌月满月: +1.84%
  → 3次满月中2次大涨,1次大跌。但剔除满月后准确率大降(avg +0.96%→+0.46%)
```

**当前判断**: 己卯在满月日表现分化——丁丑月(火+土)满月日跌，癸未月(水+土)和丙戌月(火+土)满月日涨。月干是否克日干是关键。

---

## 规则3: 丙午日 = 三指数忌日

**发现**: 丙午日(火+火)是上证、深证、创业的共同忌日。

**案例**:
```
2026-04-02 丙午日(火): 上证-0.74% 深证-1.60% 创业-2.31% 科创-2.77%
2026-06-01 丙午日(火): 上证-0.36% 深证-1.54% 创业-2.18% 科创-4.75%
2026-07-31 丙午日(火): (待验证)
```

**触发条件**: 日干支=丙午
**严重程度**: L4(高危)
**影响范围**: 全市场

## 规则4: 残月→新月 = 反弹窗口

**发现**: 月相从残月(phaseIdx=7)过渡到新月(phaseIdx=0)时，4指数反弹概率高。

**统计**:
```
残月→新月次日:
  上证 avg +0.31% 胜率69% (16次)
  深证 avg +0.55% 胜率62% (16次)
  创业 avg +0.89% 胜率62% (16次)
  科创 avg +0.97% 胜率59% (17次)
```

---

## 规则5: 科创癸亥日 = 木月爆量

**发现**: 科创在癸亥日(水+水)遇上木月(月干=甲或乙)时大幅上涨。

**案例**:
```
2025-08-22 乙(木)年 + 甲(木)月 + 癸(水)日: +8.59%
2026-06-18 丙(火)年 + 甲(木)月 + 癸(水)日: +3.82%
```

**逻辑**: 木月泄水(水生木=泄气)，但科创的癸亥水日柱太旺，泄而不断，反而随木月推动上涨。

---

## 规则6: 乙未月 = 全市场最差月

**发现**: 乙未月(木+土)是4指数共同的最差月份。

**统计**(2026-07-07 ~ 2026-07-29):
```
上证 -5.2%  深证 -11.4%  创业 -14.4%  科创 -15.6%
```

**原因**: 月干乙(木) + 月支未(土)。木克土 + 土克水。水日柱(科创癸亥/上证癸未)和火日柱(创业丙寅)全被克。

---

## 规则7: 火年(丙午) × 金日柱 = 金被火克但仍正

**发现**: 丙午年(火+火)克金日柱(庚申等)，但金日柱在火年未出现系统性下跌。

**案例**:
```
深证庚午(金): 丙午年2次, avg +1.59% — 反而强于乙巳年
创业庚午(金): 丙午年2次, avg +2.18% — 同样更强

解释: 丙午年火极旺, 火克金理论上金日柱应该弱, 但实际火年经济热→工业好(金=工业)
```

**启示**: 年克不等于一定跌。要结合年能量的宏观含义。
