## 选取流程（5步）

### Step 1: 数据范围
- 日线数据: 2024-09 ~ 2026-07-29（约450个交易日）
- 天时缓存: `data/astro/astro_calendar.jsonl`
- 排除月份: 癸酉月、甲戌月（2024年9-10月924政策市）
- 指数: sh000001(上证)、sz399001(深证)、sz399006(创业)、sh000688(科创)

### Step 2: 全60甲子海选
对每个指数，统计60个日干支每次出现时的涨跌：

```
遍历所有交易日 → 按日干支分组 → 计算每组:
  - avg: 平均涨跌幅
  - 一致性: avg>0时正的比例（avg<0时负的比例）
  - √n: 样本量开根号
```

### Step 3: 多维稳定性 + 能量克伐筛选

每个候选日柱过两重筛选：

**第一重: 跨年/跨月稳定性**

稳定性权重 = 年稳定性 × 60% + 月稳定性 × 40%

```
年稳定性: 日柱在不同流年下的 avg 是否都>0
  戊申在上证: 甲辰年+0.59%、乙巳年+0.86%、丙午年+0.31% → 3年全正 = 100%

月稳定性: 日柱在不同流月下的 avg 是否都>0
  戊申在上证: 跨6个月，6/6月正 = 100%

合稳 = 100% × 0.6 + 100% × 0.4 = 100%
```

**第二重: 年月日三层能量克伐**

日柱选定后，用年月日三层天干的五行对日柱打分：

```
能量比重: 年干 50% + 月干 30% + 日干 20%

打分规则:
  年干 vs 日干: 同气=+2 被生=+1 被克=-2 生日=-1 (权重50%)
  月干 vs 日干: 同气=+1 被生=+1 被克=-1 (权重30%)

创业丙寅(火)翻车案例:
  2025-06-26 乙(木)年 + 壬(水)月 + 丙(火)日 → -0.66%
  年干乙木生丙火(+1, 权重50%), 月干壬水克丙火(-1, 权重30%)
  总分 = +1×50% + (-1)×30% = +0.2 → 勉强正但仍翻车
  → 规则: 年干+月干两层都克日干时翻车概率大增
```

### Step 5: 定性验证

日柱必须能和指数的业务属性形成逻辑闭环：
- 上证戊申(土+金): 金融+工业=土生金
- 深证丁巳(火+火): 科技+制造=火旺
- 创业庚午(金+火): 新能源=火, 光通信=金生水→生木→生火
- 科创丙寅(火+木): 半导体散热=火, 创新研发=木生火

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 数据起始 | 2024-09-01 | 太早期数据市场结构变化大 |
| 排除政策月 | 癸酉、甲戌 | 924全市场暴涨不是纯天时信号 |
| 最小样本 | n≥4 | 日柱出现不足4次的不参与排名 |
| 年稳:月稳 | 60:40 | 年能量主导，月调节 |
| 剔除日 | 满月日、交割日 | 避免情绪/制度因素干扰 |

## 调优记录

- V1: 纯 avg 排名 → 科创癸亥+2.50%排第一，但丙午年n=1不可靠
- V2: 加年稳定性 → 癸未在丙午年衰减被惩罚
- V3: 加月稳定性 → 己卯满月日频翻车暴露
- V4: 加能量克伐 → 发现"年月日三层≥2层克日干"规律
- V5(最终): 剔除满月+交割日 + 能量分组 → 丁巳剔除后反而提升
