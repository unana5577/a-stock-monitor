# 日线 + 当日分时接入工作流框架

## 现状问题

```
前端每30秒 → GET /api/m1/stage_state → execFile stage_runner.py
                                    ↓
                             读 daily.jsonl（昨日收盘价）
                                    ↓
                             盘中看到的是昨天数据
```

**根本问题**：阶段判断用日线收盘价，但盘中 9:30-15:00 日线没更新，看到的是昨天状态。

## 数据现状

| 数据类型 | 路径 | 更新频率 | 生产者 |
|----------|------|----------|--------|
| 日线 | `data/etf/daily/{sym}/daily.jsonl` | 收盘后一次 | M1-D-ETF-Minute2Daily（n8n） |
| 分钟线 | `data/etf/minute/{sym}/{date}.jsonl` | 每分钟 | M1-C-ETF-Minute-Fetch（n8n） |

**分钟线已就绪**，字段：`time, price, pct, amount, vol, open, high, low, pre_close`

## 方案

### 整体链路

```
n8n 定时工作流 (N1-Stage-Snapshot, 每5分钟)
         │
         ├── stage_runner.py --use-minute（读日线+最新分钟价）
         │         │
         │         ├── 日线最后一根 → closes 拼最新分钟价 → detect_stage()
         │         └── 同时算出 entry_tiers（MA20 挂单价实时更新）
         │
         └── 输出 → data/stage/snapshot.json（落盘快照）

API GET /api/m1/stage_state
         │
         └── 读 data/stage/snapshot.json（毫秒级，不 execFile）
                  │
                  └── 前端 / 交易助手页 30s 轮询
```

### 新增/改动

| 文件 | 改动 |
|------|------|
| `波段策略/stage_runner.py` | 新增 `--use-minute` 参数，盘中读分钟线最新 price 代日线 close |
| `n8n-workflows/N1-Stage-Snapshot.json` | 新增定时工作流，每 5 分钟调用 stage_runner |
| `data/stage/snapshot.json` | 新落盘文件，前端读取（不需要 execFile） |
| `server/api/trade.js` | `/api/m1/stage_state` 改读 snapshot.json 快照 |
| `pages/trade/ui.js` | 轮询间隔可调（目前 30s 不变） |

### stage_runner --use-minute 逻辑

```python
# 伪代码
def compute_snapshot_live(symbol, target_day):
    rows = read_daily(symbol)
    minute_rows = read_minute_today(symbol, target_day)
    
    if minute_rows:
        # 盘中：拼最新分钟价到日线末尾
        latest = minute_rows[-1]
        live_row = {
            "date": target_day,
            "close": latest["price"],  # ← 实时价
            "open": latest["open"],
            "high": latest["high"],
            "low": latest["low"],
            "amount": sum(m["amount"] for m in minute_rows),
            "vol": sum(m["vol"] for m in minute_rows),
        }
        rows_for_stage = rows + [live_row]
    else:
        rows_for_stage = rows
    
    detect_stage(rows_for_stage, len(rows_for_stage)-1)
```

### 收益

| | 改前 | 改后 |
|----|------|------|
| 阶段数据时效 | T-1（昨天） | T+0（实时） |
| API 响应速度 | ~2s（execFile Python） | ~5ms（读 JSON 文件） |
| 前端负载 | 每次轮询触发 Python 进程 | 只读快照，不触发计算 |
| 挂单价格 MA20 | 固定（昨天 MA20） | 盘中动态更新 |
| entry_tiers | 昨天值 | 盘中最新 MA20 算 |

### 兼容

- 非交易时段（收盘后/周末）：分钟线为空，fallback 到日线最后一条
- 快照文件不存在：API 降级走 execFile stage_runner（当前逻辑）
- n8n 停掉：前端仍能读到上一次快照（不会白屏）

### 后续优化方向

1. **快照落盘加 `as_of` 时间戳**：前端显示"数据更新于 14:35"
2. **分时价格直接传给建议买入价**：`entry_tiers` 随 MA20 盘中变化
3. **成交量关联**：盘中量比实时计算，辅助判断是否"放量回调"
4. **n8n 频率可调**：波动大时 2 分钟一次，平稳时 5 分钟一次
