# 五阶段策略调度方案（新增下跌阶段）

> 状态: 设计讨论完成，待确认  
> 目标: 新增"下跌"阶段作为趋势转弱的提前信号，配合时间节点止盈

---

## 一、核心变化

| 维度 | 旧方案（4阶段） | 新方案（5阶段） |
|------|---------------|---------------|
| 阶段数 | 震荡/启动/主升/防守 | 震荡/启动/主升/下跌/防守 |
| 下跌识别 | 无 → 直接等死叉防守 | close < MA20 且 MA20斜率 < 0 |
| 止损逻辑 | 无（等死叉清仓） | 主升→下跌：80%减至50% |
| 止盈策略 | 无 | ETF长持不主动止盈，仅在时间节点（930/春节/季末）可减半仓 |
| 仓位上限 | 80% | 80%（不上杠杆） |

---

## 二、阶段定义（按优先级从高到低）

| 优先级 | 阶段 | 图标 | 判定条件 | 仓位 | 含义 |
|--------|------|------|----------|------|------|
| **1** | 🔴 **防守** | 死叉 | close < MA60 且 MA20 < MA60 | 0% | 均线空头排列，趋势完全转熊 |
| **2** | 🟢 **主升** | 多头 | close > MA20 > MA60 且 MA20斜率 > 0 且 5日不创新低 | 80% | 强势多头，趋势加速 |
| **3** | 🟡 **启动** | 萌芽 | close > MA20 且 MA20斜率 > 0（MA20可还在MA60下方） | 30%→70% | 趋势刚冒头 |
| **4** | 🟠 **下跌** | 转弱 | close < MA20 且 MA20斜率 < 0（但MA20仍>MA60，还没死叉） | 30% | 趋势转弱预警 |
| **5** | 🔵 **震荡** | 横盘 | close 在 MA20 ±3% 内 或 MA20斜率 ≈0 | 70% | 无方向横盘 |
| 默认 | 🔵 震荡 | — | 以上都不满足 | 70% | 默认保守 |

### 关键设计说明

#### 下跌 vs 防守的区别

```
主升(80%) --close<MA20 且 斜率<0--> 下跌(30%)
  └── 趋势转弱，但均线结构可能还没坏，减仓保护利润

下跌(30%) --MA20<MA60(死叉)--> 防守(0%)
  └── 均线确认空头排列，清仓等待

下跌(30%) --MA20斜率>0 且 close>MA20--> 震荡(70%)
  └── 转弱后趋势恢复，重新入场
```

**为什么需要"下跌"阶段：**
- 半导体ETF从1.76跌到1.45，死叉前整整扛了39天和-17.7%
- 如果在close<MA20且斜率转负时（约1.60附近）就减到30%，损失减少约10%
- 转弱信号出现得更早，给了"卖→等→买回"的操作空间，这正是你说的"买卖是为了更好获得利润"

#### 主升→下跌的止损

只在**牛末**触发：close < MA20 且 MA20斜率 < 0。这是趋势判断，不是固定百分比，符合你说的"关键是怎么判断趋势"。

## 三、阶段转移图

```
                    ┌───────────────────────────────────────────┐
                    │                                           │
                    ▼                                           │
     ┌─────────┐  MA20拐头+量   ┌─────────┐  MA20>MA60+nolow  ┌─────────┐
     │  震荡   │ ────────────→ │  启动   │ ────────────────→ │  主升   │
     │ 70%仓位 │               │ 30→70%  │                   │ 80%仓位 │
     └────┬────┘               └────┬────┘                   └────┬────┘
          │                         │                            │
          │  MA20斜率归0            │  close<MA20                 │  close<MA20 且
          │ ←───────────────────────│                             │  MA20斜率<0
          │                         │ 且 MA20斜率<0               │  ←── 🟠 下跌 30%
          │                         ▼                            ▼
          │                    ┌─────────────────────────┐
          │                    │     🟠 下跌 (转弱)       │
          │                    │     仓位: 30%           │
          │                    │     close<MA20          │
          │                    │     且 MA20斜率<0       │
          │                    │     但 MA20>MA60        │
          │                    └──────────┬──────────────┘
          │                               │
          │   MA20斜率>0                  │  MA20<MA60 (死叉)
          │   且 close>MA20               │
          │ ←─────────────────────────────│──────────────→
          │                               ▼
          │                    ┌─────────────────────────┐
          │                    │     🔴 防守 (空仓)       │
          │                    │     仓位: 0%            │
          │                    │     close<MA60          │
          │                    │     且 MA20<MA60        │
          │                    └──────────┬──────────────┘
          │                               │
          │   MA20>MA60 且 5日不创新低      │
          └───────────────────────────────┘
```

**防抖策略（Persist 3天）：**
- 震荡⇄启动⇄主升 之间切换需要连续3天新信号
- **下跌← 主升/启动/震荡：立即触发，不等（下跌信号不能等3天）**
- 防守← 下跌：连续3天确认
- 震荡← 下跌：连续3天确认

## 四、子策略规则（12条）

### 4.1 🔵 震荡期（3条）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R1 | 分批建底仓 | 仓位 < 70%目标 | 分3批，每批买入 总预算×23.3% |
| R2 | 盈利套利 | 浮盈 ≥ 5% 且 冷却1天 | 卖出持仓的10% |
| R3 | 回调吸筹 | 浮亏 ≥ 3% 且 仓位 < 80%预算 | 买入总预算10% |

### 4.2 🟡 启动期（2条）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R4 | 试探建仓 | 仓位=0 | 建30%底仓 |
| R5 | 突破加仓 | 30%仓位 且 close > 入场最高+2% | 加至70%仓位 |

### 4.3 🟢 主升期（2条）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R6 | 趋势加仓 | 仓位 < 80% | 逐步加至80%（每次+10%，间隔 ≥ 3天） |
| R7 | 牛末减仓 | close < MA20 且 MA20斜率 < 0（趋势转弱） | 减至50%仓位 |

> R7就是止损规则：只在趋势判断转弱时触发，不在主升中途卖出。保护牛市利润但不提前下车。

### 4.4 🟠 下跌期（2条）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R8 | 继续减仓 | 仓位 > 30% | 卖出超出的部分，降至30% |
| R9 | 转弱修复 | MA20斜率转正 且 close > MA20 | 不操作（由阶段判断转回震荡） |

> 下跌期30%仓位的作用：如果趋势恢复（斜率转正），不需要从零开始建仓，保留的30%可以快速转入震荡策略。

### 4.5 🔴 防守期（2条）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R10 | 空仓等待 | 阶段=防守 | 仓位=0，不操作 |
| R11 | 多头恢复 | MA20 > MA60 且 5日不创新低 | 转回震荡，建20%试探 |

### 4.6 时间节点止盈（1条 + 需测算）

| # | 规则 | 触发条件 | 动作 |
|---|------|----------|------|
| R12 | 节点止盈 | 930国庆前 或 春节前 或 季末（3/6/9/12月末）且 仓位>50% | 减仓50%（留一半） |

> **⚠️ 这个规则需要单独测算**。在回测中标记这些时间点的收益影响，再决定是否纳入正式策略。

## 六、回测预期对比

以半导体ETF sh512480 在 2025-10 ~ 2026-04 为例，新增"下跌"阶段的影响：

| 时间点 | 旧方案 | 新方案 | 差异 |
|--------|--------|--------|------|
| 1/28 主升高点 1.76 | 80%仓位 | 80%仓位 | 相同 |
| 1/30 close<MA20 + 斜率转负 | 还在主升，无操作 | **进入下跌，减至50%** | 提前锁定利润 |
| 2/3 继续跌到1.636 | 还在震荡，无操作 | 下跌50% | 少亏 |
| 3/20 跌到1.50 | 吸筹买入 | 继续持有30% | 不吸筹，不被套 |
| 3/24 死叉清仓 1.45 | 满仓扛-17.7% | 50%→30%扛了约-10% | 损失减少~40% |

**预期半导体ETF收益：从 -4% → 约 +2%**
