# 回调阶段方案

## 目标
- 识别主线 ETF（近10日出现过主升）
- 主线回调时给预算买入，非主线不参与
- 下跌阶段收紧阈值，防止微破 MA20 误判

## 改动

### 1. stage_detector.py — S4 下跌阈值收紧
```python
# 旧: slope < 0
# 新: slope < -0.5
```
单日微破 MA20、斜率只是微负的不判下跌 → 走 S5 震荡。

### 2. stage_runner.py — 输出 was_uptrend
```python
# compute_snapshot() 新增:
recent_stages = [detect_stage(rows, i)[0] for i in range(max(0, idx-9), idx+1)]
was_uptrend = "主升" in recent_stages
```
输出新增字段 `"was_uptrend": true/false`。

### 3. trade/ui.js — 预算按主线/非主线分
```js
const STAGE_TARGET = { '主升': 0.80, '启动': 0.30, '震荡': 0.00, '下跌': 0.00, '防守': 0.00 };
const RETRACE_TARGET = { '启动': 0.30, '震荡': 0.20, '下跌': 0.20, '防守': 0.00 };
// 主线+当前阶段 → 用 RETRACE_TARGET；非主线 → 0
```
