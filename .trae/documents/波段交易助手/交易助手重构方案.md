## 4. 板块分配：动态

### 逻辑

```
/ GET /api/m1/market_state → { state: "上升"|"震荡"|"下跌" }

  state === "上升"  → 科技 70% / 资源 30%  （进攻）
  state === "震荡"  → 科技 50% / 资源 50%  （均衡）
  state === "下跌"  → 科技 30% / 资源 70%  （防御）
  未获取到          → 50/50（兜底）
```

### 落地方式

在 `tradeSuggestions` 计算中，当目标权重算完后，按板块再平衡：如果科技板块总和超过动态上限，等比例缩减所有科技品种的建议金额。
