# ETF 页面优化：代码自动补全 + 阵营分布卡片

## 一、代码自动补 sh/sz

**文件：** `pages/etf/ui.js` — `submitEtfForm()` 方法

**规则：**
- 用户输入纯数字（如 `562590`/`159995`）→ 自动补前缀
  - 以 `5` 开头 → 补 `sh`
  - 以 `1` 开头 → 补 `sz`
  - 其他 → 补 `sh`
- 用户已手动输入 `sh`/`sz` → 不处理，直接校验
- 校验规则不变：`/^(sh|sz)\d{6}$/`

**改动：** 在 `submitEtfForm` 开头插入 3 行自动补全逻辑。

## 二、阵营分布卡片

### 位置

放在 **AI 板块轮动解读** 和 **归一分析** 之间，拉通一整行：

```
┌─ AI 板块轮动解读 ────────────────────────────────┐
└─────────────────────────────────────────────────┘

┌─ 阵营分布 ──────────────────────────────────────┐
│  ┌──────────────┐  ┌─────────────────────────┐  │
│  │ 柱状图        │  │ 科技 (7只)              │  │
│  │ ██████ 科技   │  │  硬件: 半导体 通讯 材料  │  │
│  │ ██ 资源       │  │  软件: 云计算 游戏      │  │
│  │              │  │  新质: 商业航天 机器人   │  │
│  └──────────────┘  │  生物: 创新药            │  │
│                    │ 资源 (2只)              │  │
│                    │  大宗: 有色金属          │  │
│                    │  泛能: 新能源            │  │
│                    └─────────────────────────┘  │
└─────────────────────────────────────────────────┘

┌─ 归一分析 ──────────────────────────────────────┐
└─────────────────────────────────────────────────┘
```

### 布局方案

一张 `q-panel` 卡片，`grid grid-cols-1 md:grid-cols-3` 两栏：

| 左栏 (1/3) | 右栏 (2/3) |
|-----------|-----------|
| ECharts 柱状图，200px 高 | 按阵营分组，显示子分类标签 + 板块名 |

- 柱状图：科技蓝色 `#3B82F6`、资源绿色 `#10B981`
- 右栏：每个子分类一行小胶囊标签（如 `硬件 半导体 通讯设备 半导体材料`），复用现有 Tailwind
- 数据来源：`etfCategoryMap` + `etfSubCategoryMap`，纯 computed，不调 API

### 实现的文件

| 文件 | 改动 |
|------|------|
| `pages/etf/index.html` | 在 AI 区块和归一分析之间插入阵营分布卡片 HTML |
| `pages/etf/ui.js` | 新增 `categoryBreakdown` computed + `renderCategoryBar()` + 模板用的变量 return |

### 柱状图实现要点

- `echarts.init`，复用现有 `chartInstances` 对象（新增 `categoryBar` 键）
- `watch` ETF 配置变化后自动重绘
- 最小高度 180px，自适应
