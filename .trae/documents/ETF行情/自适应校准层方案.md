# 自适应校准层方案

> 状态: 设计阶段  
> 目标: 在五阶段策略之上叠加"与持有的比较"，动态调整每只ETF的交易参数

---

## 一、核心思路

```
每只ETF维护两本账:
  ┌─────────────────┐     ┌─────────────────┐
  │  策略账户        │     │  影子持有账户     │
  │  实际买卖操作     │ vs  │  从第一天起持有不动 │
  │  实际 P&L        │     │  理论 P&L         │
  └────────┬────────┘     └────────┬────────┘
           │                       │
           └───────────┬───────────┘
                       │
                       ▼
            ┌──────────────────────┐
            │  比较器 (每日一次)     │
            │  策略P&L vs 持有P&L   │
            └──────────┬───────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
    策略领先         持平          策略落后
    (>持有+3%)      (±3%内)       (<持有-3%)
    ┌──────┐      ┌──────┐      ┌──────┐
    │保持/  │      │ 不动  │      │ 放宽  │
    │收紧参数│      │       │      │ 参数  │
    └──────┘      └──────┘      └──────┘
    多交易          中性          少交易
```

**直觉**: 
- 通信ETF在趋势中，策略因为频繁交易落后于持有 → 自动放宽卖出阈值（5%→7%→10%）、减少套利 → 持仓时间变长 → 追上持有收益
- 半导体ETF在横盘/阴跌中，策略领先或打平 → 保持或收紧阈值 → 继续做网格

## 二、可校准的参数（每只ETF独立）

| 参数 | 默认值 | 校准方向 | 含义 |
|------|--------|----------|------|
| `sell_trigger_pct` | 5.0% | 放宽→更大 | 涨多少触发套利 |
| `buy_trigger_pct` | 3.0% | 放宽→更大 | 跌多少触发吸筹 |
| `sell_ratio` | 0.10 | 缩小→更小 | 每次卖多少 |
| `find_buy_range` | ±1.0% | 放宽→更大 | 找底加仓的MA20偏离容忍度 |
| `find_buy_pct_max` | 8.0% | 放宽→更大 | 找底加仓的浮盈上限 |

**校准逻辑**: 策略落后时 → 放宽阈值（减少无谓交易，接近持有）；策略领先时 → 收紧阈值（增加网格利润）。

---

## 三、校准规则（3条）

| # | 规则 | 条件 | 动作 |
|---|------|------|------|
| C1 | 收紧 | 策略 P&L ≥ 持有 P&L + 3% | sell_trigger -0.5%, buy_trigger -0.5%, sell_ratio +0.02, find_range 收窄 |
| C2 | 保持 | \|策略P&L - 持有P&L\| < 3% | 参数不变 |
| C3 | 放宽 | 策略 P&L ≤ 持有 P&L - 3% | sell_trigger +1.0%, buy_trigger +1.0%, sell_ratio -0.02, find_range 放宽 |

**冷却**: 每次校准后至少等待 5 个交易日才能再次调整，防止频繁振荡。

**边界**: 
- sell_trigger 限制在 [3%, 12%]
- buy_trigger 限制在 [2%, 8%]  
- sell_ratio 限制在 [0.04, 0.20]
- find_buy_range 限制在 [±0.5%, ±5%]

## 四、在通信ETF上的预期效果

回测中通信ETF全程在涨。用校准层后：

```
10/09 建仓, 策略仓位=持有仓位, P&L打平
  ↓ 持有 P&L 持续领先（因为是纯上涨趋势）
  ↓ C3 触发: sell_trigger 从 5%→6%→7%→...→10%
  ↓ 卖出越来越难触发，策略越来越像持有
  ↓ 最终: 通信ETF的套利次数从 3次降到 1-2次
  ↓ 收益从 +42% 提升到接近 +50%+
```
