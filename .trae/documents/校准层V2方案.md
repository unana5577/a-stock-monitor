# 校准层V2：只在主升期放宽

> 改动量: ~15行  
> 目标: 震荡/启动/下跌/防守用固定参数，主升期自动放宽卖出阈值

---

## 逻辑

```
所有阶段:
  calibrate() 默认 return None (不校准)

主升阶段:
  策略落后持有 >1% → C3放宽: sell_trigger +1%, sell_ratio -0.02
  策略领先持有    → 不收紧 (趋势中交易永远比持有差)
  sells_trigger 上限 12%, sell_ratio 下限 0.04
  冷却 5 天
```

---

## 修改文件

| 文件 | 改动 |
|------|------|
| `adaptive_params.py` | `calibrate()` 改为只在主升期做 C3 放宽，去掉 C1/C2 |
| `adaptive_params.py` | `LEAD_THRESHOLD` 改为 1.0（更快响应） |
