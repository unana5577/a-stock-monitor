# 天时回测 V3：逐月相详情 + 信号因子拆解 + 能量堆叠验证

## 用户 5 个问题

### Q1: 每个新月都有爆拉吗？过程呢？

**当前差距**：周期报告只给了累积值，没把每次新月单独列出来对比。你说的对——"科创在新月期累积+26%"不说明每次新月都有用。

**需要做**：
- 列出**每次新月 ±3天**（共30次）的4指数涨跌明细表
- 统计"新月日当天涨"的比例、"新月后3天累积涨"的比例
- 反例标注：哪些新月窗口是跌的？在什么月份/干支背景下？
- 输出格式：
```
新窗口 #5: 2025-09-22(甲午日) ~ 2025-09-26
  9/22: 上证+0.22% 深证+0.67% 创业+0.55% 科创+3.38%
  9/23: 上证-0.18% 深证-0.29% ...
  9/24: 上证+0.83% ...
  累积: 上证+0.87% 深证+2.18% 创业+2.04% 科创...
  → 结论: 偏强 ✓

新窗口 #10: 2025-11-21(甲午日) ~ 2025-11-25
  11/21: 上证-2.45% 深证-3.41% ...
  → 结论: 大跌 ✗ (反例！在丁亥月火水冲背景下)
```

### Q2: 月亏开始（满月→亏凸月）是否有暴跌？

- 列出**每次满月后的第一段亏凸月期间的4指数涨跌**
- 统计满月后1天/2天/3天分别的涨跌分布
- 对标"月满则亏"的验证

### Q3: 信号合成器因子 + 调试方法

**当前三个因子**：

| 因子 | 含义 | 计算方式 |
|------|------|----------|
| W1 × 日干得分 | 纯日干效应 | ETF在每个天干下的历史平均涨跌 |
| W2 × 月干交互 | 月背景调制 | 同是"丙日"，但"月干=甲"vs"月干=辛"下表现不同 |
| W3 × 年干交互 | 年背景调制 | 同是"丙日"，但在乙巳年vs其他年份下表现不同 |

**当前缺的因子**（可能需要加）：

| 候选因子 | 说明 |
|----------|------|
| 地支三合局 | 申子辰合水、巳酉丑合金等——日支×月支×年支形成合局时的能量 |
| 六十甲子纳音 | 每个干支有纳音五行（如甲子=海中金），可能比天干更细 |
| 月相调节 | 日干得分 × 月相修正（满月日权重打折、新月日权重放大） |
| 趋势动量 | 前5日涨跌 × 干支信号叠加 |

**调试方法**：
1. 每次跑脚本，输出全样本 r 和方向正确率
2. 新增因子后重新训练权重，比较 r 是否提升
3. 用留出法（holdout）：最后30天不参与训练，用训练好的权重预测最后30天，看准确率
4. 持续追踪"强信号(≥0.5)方向正确率"，目标>70%

### Q4: 年→月→日是否逐步叠加？

**当前设计**：三个独立因子加权求和，**不是**严格的逐步叠加。

**合理的逐步叠加逻辑应该是**：

```
Step 1: 年定基调 → 乙巳年(木火) → 全年偏木火，利好木火属ETF
Step 2: 月定方向 → 壬午月(水火) → 水火上冲，木火ETF被水火叠加
Step 3: 日定点位 → 甲子日(木水) → 木水日，在木火年+水火月背景下
```

需要在报告里加一个"逐步叠加验证"板块：
- 纯日干 vs 日干+月背景 vs 日干+月+年背景 → 哪个组合的 r 更高？
- 证明叠加确实有效

### Q5: 流年流月能量有什么意义？

**当前问题**：只说"年乙巳木火、月壬午水火"，但没有验证这个能量偏斜到底有什么预测价值。

**需要做**：
- 计算每个月的"五行能量签名"（如壬午月=水3火2 → 水偏盛）
- 与ETF实际表现做交叉验证：
  ```
  壬午月(水偏盛): 
    理论: 水利好水性ETF(云计算)、火性ETF被克
    实际: 云计算+0.22%、游戏+0.56%(火？不符)、通信+0.61%
    偏离: 游戏(火)在"水偏盛月"涨了0.56% → 理论不成立或取象错了
  ```
- 统计"理论方向正确率"：五行能量偏哪，对应ETF 是否跟着偏

## 改造方案：一个综合报告脚本

不建4-5个独立脚本了，合并成一个主控脚本 `treasolo/m1_astro_full_report.py`，一个命令跑出完整报告。分 7 个板块：

| # | 板块 | 解决问题 |
|---|------|----------|
| 1 | 每次新月窗口 ±3天明细 | Q1 |
| 2 | 每次满月→亏凸月转折明细 | Q2 |
| 3 | 因子列表 + 相关性贡献拆解 | Q3 |
| 4 | 逐步叠加验证（日 vs 日+月 vs 日+月+年） | Q4 |
| 5 | 流月五行能量 × ETF交叉验证 | Q5 |
| 6 | 信号合成器当前预测 | Q3 |
| 7 | 质量评估 + 调试建议 | Q3 |
