# 天时能量分析：月相节点 + 干支五行 × 板块ETF 取象

## 核心理念

不做粗糙的"8个月相平均涨跌"，而是做有意义的**时间节点分析**和**干支能量画像**：
- 月圆/月缺是转折窗口，关注节点前后 N 天的运动方向
- 干支不只是 60 个标签，每个干支有五行属性，与板块 ETF 的五行取象共振或相克
- 先出数据，我们对着数据统一理解后，再决定前端展示方式

## 第二步：运行脚本输出原始数据

### 脚本1：月相节点 × 大盘转折分析

**不是**简单算 8 个月相的平均值，而是分析**关键节点**：

| 节点 | 分析内容 |
|------|----------|
| 满月日当天 | 4个指数涨跌幅 |
| 满月前1天/前2天/前3天 | 累积涨跌方向 |
| 满月后1天/后2天/后3天 | 转折方向（月满则亏是否成立） |
| 新月日当天 | 4个指数涨跌幅 |
| 新月前1-3天 | 探底特征 |
| 新月后1-3天 | 反弹特征（月缺则盈是否成立） |
| 上弦月/下弦月 | 趋势中继点，各前后2天 |

输出示例：
```
满月节点统计（2025-05至今）:
  满月日: 2025-05-12, 2025-06-11, 2025-07-10, ...
  
  满月日当天:
    上证 avg +0.12% (胜率55%)
    科创 avg +0.38% (胜率67%)  ← 注意
  
  满月前3天→满月日: 上证累积 +0.45% 
  满月日→满月后3天: 上证累积 -0.32%  ← 月满则亏？
```

### 脚本2：干支五行 × 板块ETF 能量分析

**核心逻辑**：

1. 把 60 个日干支拆成**天干+地支**，每个天干地支有五行：
   - 天干五行：甲乙木、丙丁火、戊己土、庚辛金、壬癸水
   - 地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土

2. 把每个 ETF 按取象归入五行

3. 交叉分析：
   - **天干能量日**：甲/乙日 → 木性 ETF（创新药）表现？→ 统计结果
   - **天干克伐日**：庚/辛日（金克木）→ 木性 ETF 是否被压制？
   - **地支三合局**：申子辰合水局日 → 水性 ETF 是否受益？
   - **流月能量**：当前月干支 × 日干支的组合效应

4. 输出按「五行生克」组织，而不是按 60 个干支罗列：

```
日干能量画像（2025-05至今）:

  木日（甲乙日）:

    新能源ETF(火)  avg +0.15%         ← 木生火，受益
    半导体ETF(金)  avg -0.11%         ← 金克木，但金被木耗？
    有色金属(土)   avg -0.05%         ← 木克土
  
  火日（丙丁日）:
    新能源ETF(火)  avg +0.42% 胜率65%  ← 同气，明显偏强

    通信ETF(金)    avg -0.18%         ← 火克金
    ...
  
  金日（庚辛日）:
    半导体ETF(金)  avg +0.22%
    机器人ETF(金)  avg +0.19%
    ...
  
  水日（壬癸日）:
    云计算ETF(水)  avg +0.18%

流月能量（2025-05起各月干支）:
  乙巳月(木火): 科技板块偏强, 资源偏弱
```

## 输出方式（两阶段）

### 第一阶段：纯数据报告（无前端）

先跑脚本出数据，我把结果**直接贴给你看**。我们对着数据理解：
- 哪些规律是显著的（胜率>60%、样本>5次）
- 哪些是噪声（样本太少或波动太大）
- 月满则亏/月缺则盈在中国A股是否成立
- 干支生克对板块的影响是否符合五行理论

### 第二阶段：统一思路后做前端

理解一致后，再做 `pages/astro/` 的回测展示面板。到时候可以做成：
- 月相时间轴 + 大盘涨跌标注
- 五行雷达图（各 ETF 在不同日干下的胜率）
