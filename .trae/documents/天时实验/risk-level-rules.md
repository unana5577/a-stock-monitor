# 天时风险等级逻辑

> 更新时间：2026-08-13
> 数据来源：`八字/feature_stats.json`（特征胜率统计）+ `八字/risk_rules.json`（规则配置）

## 一、概述

天时风险提示**只做风险标注，不做涨跌预测**。风险等级由「风险因子数量叠加」得出，高危因子直接拉满 L4。

风险分两个维度：
- **大盘风险**：影响整个市场，对所有人生效
- **个人风险**：只影响命主本人（由八字日柱 vs 当日干支判定）

两个维度的风险因子**统一叠加**成一个总风险等级。

---

## 二、风险因子清单

### ① 大盘风险因子

| 因子 | 判定规则 | 历史胜率/依据 | 等级贡献 |
|------|---------|--------------|---------|
| 丙午日 | 日柱 = 丙午 | 胜率约 25%，三指数共同忌日 | 🔴 高危（直接 L4） |
| 乙未月 | 流月 = 乙未 | 历史最差月（上证-5.2%/深证-11.4%/创业-14.4%/科创-15.6%） | 普通因子 +1 |
| 交割日 | 每月第三个周五（节假日顺延） | 胜率 40%~45%，偏跌 | 普通因子 +1 |
| 新月窗口 | 农历廿九~初二（moonAge <1.5 或 ≥28） | 胜率 41.7%~47.2%，偏跌 | 普通因子 +1 |

### ② 个人风险因子（需设置命主八字后生效）

| 因子 | 判定规则 | 含义 | 等级贡献 |
|------|---------|------|---------|
| 克伐日（破财） | 当日天干克命主日柱天干 | 情绪/操作易失误，容易漏财 | 普通因子 +1 |
| 进财日 | 当日天干生命主日柱天干 | 财气/助力旺，宜进攻 | 利好（非风险，不计入等级） |

### ③ 非风险因子（客观标记，不参与风险等级）

| 因子 | 判定规则 | 历史胜率 | 说明 |
|------|---------|---------|------|
| 满月窗口 | 农历十四~十六（moonAge 13~16.5） | 44.7%~56.3% | 中性偏涨，非风险 |
| 双土日 | 日干五行=土 且 日支五行=土 | 54%~63% | 偏涨，非风险 |

## 三、风险等级计算逻辑

### 公式

```
若命中高危因子（丙午日）：
    风险等级 = L4 高危（直接拉满，不再叠加）
否则：
    风险等级 = 命中的普通风险因子数量（大盘 + 个人）
```

### 等级映射

| 命中普通因子数 | 风险等级 | 标签 |
|---------------|---------|------|
| 0 | L0 | 安全 |
| 1 | L1 | 注意 |
| 2 | L2 | 谨慎 |
| 3 | L3 | 危险 |
| ≥4 | L4 | 高危 |

### 举例

```
新月                         = L1 注意
新月 + 克伐(破财)             = L2 谨慎
新月 + 交割 + 克伐(破财)      = L3 危险
新月 + 交割 + 乙未月 + 克伐   = L4 高危
丙午日                       = L4 高危（直接拉满）
丙午日 + 任何其他因子         = L4 高危（封顶）
```

---

## 四、等级含义

| 等级 | 标签 | 含义 | 操作建议 |
|------|------|------|---------|
| L0 | 安全 | 无风险因子命中 | 可正常操作 |
| L1 | 注意 | 命中 1 个低风险因子 | 注意仓位 |
| L2 | 谨慎 | 命中 2 个风险因子 | 建议降低仓位 |
| L3 | 危险 | 命中 3 个风险因子叠加 | 建议谨慎防守 |
| L4 | 高危 | 命中丙午日，或 4 个及以上因子叠加 | 建议空仓观望 |

## 六、配置文件对应

| 配置项 | 文件 | 说明 |
|--------|------|------|
| 风险规则 | `八字/risk_rules.json` | 定义因子、判定类型、level（高危=4，普通=1） |
| 特征胜率 | `八字/feature_stats.json` | 各因子的历史胜率（数据驱动依据） |
| 日柱候选 | `八字/astro_dynamic_vars.json` | 指数日柱 + 命主日柱来源 |
| 计算实现 | `server/api/astro.js` | checkRiskFactors（叠加）+ 风险等级映射 |

### risk_rules.json 的 level 约定

- `level = 4`：高危因子（丙午日），命中直接 L4
- `level = 1`：普通因子（新月/交割/乙未月），按数量叠加
- `level = 0`：非风险因子（满月/双土日），只做客观标记，不计入等级

> 注：交割日由 `isDeliveryDay()` 单独计算（非简单规则匹配），在风险等级里按「普通因子 +1」处理。
