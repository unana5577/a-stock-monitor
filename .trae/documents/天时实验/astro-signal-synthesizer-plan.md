## 层1：月相周期逐次分析（替代平均值）

**不是"满月日 avg +0.09%"，而是列出每一次：**

```
第1个周期: 2025-05-12(满月) ~ 2025-06-11(满月)
  月相轴: 满月→亏凸月→下弦月→残月→新月→娥眉月→上弦月→盈凸月→满月
  时间: 2025-05-12 ~ 2025-06-11 (31天, 22个交易日)
  上证累积: +1.23%  深证: +2.15%  创业: +3.40%  科创: +4.10%
  周期内最弱日: 无大跌
  周期内最强日: 2025-05-28(新月) 科创+8.59%

第2个周期: 2025-06-11 ~ 2025-07-10
  ...
```

这样能看到每个周期的累积方向、周期内波动特征，而不被平均值掩盖。

## 层3：★核心★ 多周期干支信号合成器

### 理念

不只看"甲日半导体会涨吗"，而是把**年干、月干、日干三层能量合成为一个信号**：

```
某一天的信号 = W1 × 日干得分(sym, dayStem) + W2 × 日干×月干交互得分(sym, dayStem, monthStem) + W3 × 日干×年干交互得分(sym, dayStem, yearStem)
```

### 第一步：单层得分表（从历史数据训练）

对每只ETF，统计在每个天干日下的历史平均涨跌，作为该ETF对"日干=甲"的基础得分：

```
得分矩阵 (ETF × 10天干):
        甲   乙   丙   丁   戊   己   庚   辛   壬   癸
半导体  -0.15 +0.63 -0.47 +0.86 +0.56 +0.67 -0.34 +0.71 -0.27 +0.32
通信    +0.05 +0.38 -0.08 +0.94 +1.16 +0.96 -0.06 +0.98 +0.41 +1.16
...
```

### 第二步：交互得分表

日干×月干交互（精细到"月干=甲 且 日干=丙"的情况）：

```
半导体 在 月甲+日丙: avg +1.23% (n=5)
半导体 在 月乙+日丙: avg -0.45% (n=4)
→ 同是丙日，但月干不同，表现差异大！
```

### 第三步：权重训练

用最近N天数据做简单线性回归，训练 W1/W2/W3，使得合成信号与实际涨跌的相关系数最大。

### 第四步：输出

```
=== 信号合成器已训练 ===
训练数据: 2025-05 ~ 2026-06 (237天)
相关系数 r: 0.42（正相关，中等强度）

=== 当前信号（2026-06-15）===
当前天时: 乙巳年 壬午月 甲子日
年能量: 木火  月能量: 水火  日能量: 木水

各ETF合成信号（>0看多, <0看空）:
  通信ETF: +0.82 ★★★ (强烈看多)
  半导体:  +0.45 ★★
  新能源:  +0.38 ★★
  有色金属: +0.21 ★
  创新药:  -0.08 (中性偏空)
  游戏:    -0.35 ☆☆ (看空)
  云计算:  -0.42 ☆☆ (看空)
```
