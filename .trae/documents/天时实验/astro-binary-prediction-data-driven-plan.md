# 天时预测重构 — 从手工打分转向数据驱动的涨跌概率

## 一、Summary

当前天时预测的数值（`score_map` 的同气+2/被生+1、`energy_weights` 的 50/30/20、`risk_rules.json` 的 score_delta -1/-2）全部是**拍脑袋**设定，无数据依据。本次重构把预测改为**二元涨跌分类**，数值全部从历史数据统计得出：

- **特征胜率**：直接历史统计（数据驱动，无需手填）
- **特征权重**：初始用样本数加权，再用滚动回测网格搜索调优
- **输出**：看涨概率 P(涨) + 涨/跌方向，不再输出无意义的 score 数值

## 三、新预测模型设计

### 3.1 特征定义（从 astro_calendar.jsonl 可提取，离散化）

每个指数日柱，每日产生以下特征：

| 特征 | 取值（离散） |
|------|-------------|
| `year_rel` | 年干 vs 日柱天干：同气/被生/被克/泄/柱克 |
| `month_rel` | 月干 vs 日柱天干：同上 5 类 |
| `day_rel` | 日干 vs 日柱天干：同上 5 类 |
| `phase` | 月相：满月窗口/新月窗口/其他 |
| `risk` | 风险因子：丙午日/双土日/乙未月/交割日/无 |

### 3.2 特征胜率统计（数据驱动核心）

对每个指数、每个特征取值，统计历史涨跌胜率：

```
win_rate(特征=X) = 历史上该特征出现时上涨天数 / 该特征出现总天数
```

产出 `八字/feature_stats.json`，结构：

```json
{
  "indices": {
    "sh000001": {
      "pillar": "戊申",
      "features": {
        "year_rel": {"同气": {"win_rate": 0.52, "n": 80}, ...},
        "month_rel": {...},
        "day_rel": {...},
        "phase": {"满月窗口": {"win_rate": 0.41, "n": 20}, ...},
        "risk": {"丙午日": {"win_rate": 0.20, "n": 5}, ...}
      }
    }
  }
}
```

### 3.3 预测（运行时，替换手工打分）

对某天某指数，查各特征的胜率，加权平均得到看涨概率：

```
P(涨) = Σ (权重_i × win_rate_i) / Σ 权重_i
```

- 默认权重 = 样本数 `n`（样本越多越可信，数据驱动，无需手填）
- 方向：P(涨) > 0.5 → 涨，否则 → 跌

### 3.4 数值调优（回答"数值如何调优"）

三层调优，全部数据驱动：

| 调优对象 | 方法 |
|----------|------|
| 特征胜率 | 历史统计自动得出（无需调） |
| 特征权重 | 滚动回测网格搜索：权重从样本数出发，在训练/验证集上找最优组合 |
| 日柱选择 | 滚动窗口对比主/备选日柱命中率，切换更优日柱（复用 m1_daily_calibrate.py 机制） |

## 五、关键决策与假设

1. **特征粒度用「生克 5 类」而非「60 甲子」**：2 年约 450 个交易日，60 甲子每种仅约 7 次，样本不足；5 类每类约 90 次，足够统计。
2. **组合用「加权胜率」而非「朴素贝叶斯」**：更直观、可解释、权重可调；朴素贝叶斯假设特征独立（天干与月相实际不独立）。
3. **输出保留概率**：虽然用户只要涨/跌，但 P(涨) 数值能让用户判断信号强弱（如 65% 看涨比 51% 看涨更有信心），且调优和准确率对比需要概率。
4. **样本数不足的特征回退**：某特征 `n < 5` 时，该特征不参与加权（回退到先验胜率 50%）。
5. **数据范围**：用 `data/index/daily/` 截至 2026-06-15 的数据统计；数据同步到最新后重跑脚本即可更新。

6. 改造 `m1_daily_calibrate.py`：适配新模型做日柱切换。
7. 写权重调优脚本（可选第二步）：滚动回测网格搜索最优特征权重。
