# 交易助手 UI 精简方案

## 目标

6 件事：初始资金弹框化、删除模拟设置面板、持仓加修改按钮、上传截图移位置、五阶段标签精简排序。

---

## 1. 初始资金 → 总资金卡片弹框

**现状**: 模拟账户设置里有个"初始资金"输入框，跟总资金数字对不上。

**改为**: 总资金卡片右侧加一个小编辑按钮（🖉），点击弹 Modal：

```
┌───────────── 弹窗 ─────────────┐
│  设置总资金                      │
│  [ 100000        ] 元            │
│  当前: 现金 ¥80,000 + 持仓 ¥20,000 │
│  修改后剩余现金自动调整           │
│              [取消]  [确认]       │
└────────────────────────────────┘
```

- 确认后: `simState.cash = 新总资金 - 现持仓市值`
- 同时 `simConfig.initialCash = 新总资金`（重置时也用这个）
- 负数自动截断为 0

**新 ref**: `capitalModalOpen`, `capitalModalValue`

---

## 2. 删除模拟账户设置面板

**删掉** `index_m1.html` 第 751-805 行整个块（模拟账户设置 + 风控预警 + 板块仓位）。

风控预警和板块仓位**保留**，挪到总览面板的三卡片下方，作为独立一行。

---

## 3. 持仓明细加修改按钮

持仓表（标的/份额/均价/现价/市值/收益）加一列"操作"：

```
标的    份额   均价   现价   市值   收益   操作
通信ETF  5000  1.45  1.60  8000  +750  [修改]
```

点"修改"弹小弹窗：可编辑份额和均价，确认后更新 `simState.positions[sym]`。

**新增方法**: `editPosition(sym)` → 打开弹窗，`confirmEditPosition()` → 写入

---

## 4. 上传持仓截图 → 移到持仓明细

将"上传持仓截图"按钮和"重置"从模拟设置区移到持仓明细（`tradeBottomTab === 'positions'`）的标题栏右侧：

```
账户明细                    持仓 | 交易记录
持仓数：3              [上传截图] [重置]
```

---

## 5. 五阶段标签精简

**删除**: 价格 `@1.603` 显示
**排序**: 主升 / 防守 优先排在前面（最重要），然后启动 / 下跌 / 震荡

```
🟢 通信ETF: 主升    🔴 云计算: 防守    🟢 半导体ETF: 主升    🟢 机器人ETF: 主升
```
