# 分时成交量卡片需求文档

## 概述

在 Dashboard 首页添加一个新的"分时成交量"卡片，展示当日成交量的分时走势和预估数据。

## 位置

现有"成交额"卡片的下方（或其他合适位置）

## 显示内容

### 1. 标题行
- 左侧：今日分时成交
- 右侧：预估增量/缩量（实时）

### 2. 今日成交额（最显眼，大字体）
- 格式：分时累计成交量
- 颜色：橙色

### 3. ETF信息行
- 格式：ETF 5841.0亿 占比22.1%

### 4. 预估增量/缩量显示
- 格式：增量 +19.3% / 4247.2亿
- 颜色：增量红色，缩量绿色

### 5. 分时图表
- 图表类型：每分钟成交量分钟曲线（不是累计量），和指数曲线一样
- Y轴：隐藏（不显示刻度）
- X轴：隐藏（不显示时间标签）
- 曲线样式：橙色，平滑

### 6. 数据说明（底部小字）
- 显示数据起始时间，如：数据起始: 11:06

## 计算公式

### 预估量能

预估全天量能 = 当前累计成交量 + 当前累计成交量[前一分钟成交量] × 剩余分钟数
```

说明：
- 当前累计成交量：当日分时数据最后一分钟的累计值（单位：万元）
- 当前累计成交量[前一分钟]：当日分时数据倒数第二分钟的成交量（单位：万元）
- 剩余分钟数 = 240 - 已请求分钟数（从9:30到15:00共240分钟）

### 预估增量
```
预估增量 = 预估量能 - 昨日全日成交量
增量百分比 = (预估增量 / 昨日全日成交量) × 100%
```

说明：
- 昨日全日成交量：从 `/api/market/amount_daily` 获取上个交易日的 total 字段
- 单位转换：API返回单位是元，需要转换为万元进行比较

## 数据来源

### 1. 分时数据接口（实时）

**用途**：交易时间内的曲线展示 + 预估量能计算

**实时API**：腾讯 `qt.gtimg.cn`
- 上证指数：`sh000001`
- 深证成指：`sz399001`（备用：`sz399106`）

**数据组成**：
```
分时成交额 = 上证指数.amount + 深证成指.amount
```

**数据单位**：万元

**存储文件**：`data/volume-YYYYMMDD.jsonl`
- 格式：`["HH:MM", 累计成交额]`（每行一个时间点）
- 更新频率：交易时间内每30秒

### 2. 日线数据接口（收盘后）

**用途**：收盘后的准确数据分析

**接口**：新浪 `akshare.fund_etf_hist_sina`
```python
import akshare as ak

# 上证指数
sh = ak.fund_etf_hist_sina(symbol='sh000001')
# 深证成指
sz = ak.fund_etf_hist_sina(symbol='sz399001')
```

**数据组成**：
```
日线成交额 = 上证指数.amount + 深证成指.amount
```

**数据单位**：元

**存储文件**：`data/market-amount-daily.jsonl`
- 格式：`["YYYY-MM-DD", 总成交额, 上证成交额, 深证成交额]`（单位：元）

### 3. 数据接口对比

| 类型 | 接口 | 数据源 | 单位 | 包含内容 |
|------|------|--------|------|----------|
| 分时 | 腾讯快照 | qt.gtimg.cn | 万元 | 指数成分股 |
| 日线 | 新浪ETF历史 | fund_etf_hist_sina | 元 | 股市 + ETF |

### 4. 前端API调用

1. `/api/snapshot/latest` - 获取当日分时数据
   - `sentiment.volumeSeries` - 当日分时累计成交量数组
   - `sentiment.t1_day` - 上个交易日日期

2. `/api/market/amount_daily` - 获取昨日全日成交量
   - 查询参数：`start={t1Day}&end={t1Day}`
   - 返回字段：`items[].total`（单位：元）

## 旧版技术实现要点（参考）

### 单位统一
- `volumeSeries[].volume` 单位：万元
- `amount_daily[].total` 单位：元
- 计算时需要将元转换为万元：÷10000

### 时间计算
- 分时数据时间范围：9:30 - 11:30（上午）+ 13:00 - 15:00（下午）= 240分钟
- 已请求分钟数 = 最后时间点 - 第一个时间点
- 剩余分钟数 = 240 - 已请求分钟数

### 图表数据处理
- 输入：累计成交量数组
- 输出：每分钟成交量形成曲线

## 验收标准

1. 卡片正确显示预估成交额（单位：亿元）
2. 预估增量/缩量显示正确（基于昨日全日成交量计算）
3. 图表正确显示每分钟成交量的变化趋势
4. 交易时间内数据实时更新
