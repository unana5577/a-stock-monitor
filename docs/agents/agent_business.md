## 计算公式规范

### Alpha超额收益
```
Alpha = ETF涨跌幅 - 基准涨跌幅
```
数据需求：ETF收盘价（5日/20日）、基准指数收盘价（5日/20日）

### MA斜率
```
斜率 = (当前MA - 3日前MA) / 3日前MA * 100%
```
数据需求：ETF收盘价、MA窗口（5日、20日）

### 乖离率风险等级
```
乖离率 = (收盘价 - MA5) / MA5 * 100%
```
数据需求：ETF收盘价、MA5值、60日历史数据

### 资金热度
```
热度占比 = (ETF成交额 / 全市场ETF成交额) * 100%
热度变化 = 今日占比 / 昨日占比
```
数据需求：ETF成交额、全市场ETF成交额
