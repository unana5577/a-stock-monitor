1. 自由增删分类（不限数量和名称）

## 三、ETF代码规则

### 代码格式
- **必须包含交易所前缀**：`sh`（上交所）或 `sz`（深交所）
- 6位数字：
  - 以 `5` 开头 = 上交所（sh）
  - 以 `1` 开头 = 深交所（sz）
- ✅ 正确格式：`sh512480`、`sz159995`
- ✅ 自动补全：输入 `512480` 自动补全为 `sh512480`
- ❌ 错误格式：`512480`（缺前缀）、`51248`（位数不对）

### ETF验证
点击验证按钮后，系统会检查：
- ✅ **有效**：显示数据天数、起始日期
- ⚠️ **警告**：数据不足300天（仍可使用）
- ❌ **无效**：代码错误或无数据

## 四、数据存储

### 1. sector-profile.json
存储分类关系和ETF绑定：

```json
{
  "groups": {
    "半导体": "硬件",
    "游戏": "消费",
    "新能源": "资源"
  },
  "custom_groups": [
    "资源",
    "硬件",
    "软件",
    "防守",
    "进攻",
    "医疗",
    "消费"
  ],
  "etf_bindings": {
    "半导体": "sh512480",
    "游戏": "sh516010",
    "新能源": "sh516160"
  },
  "updated_at": "2026-03-10T15:30:00.000Z"
}
```

### 2. sector-proxy.json
存储ETF代码映射（自动同步）：

```json
{
  "default_variant": "etf",
  "force_etf": true,
  "variants": {
    "etf": {
      "半导体": "sh512480",
      "云计算": "sh516510",
      "游戏": "sh516010"
    }
  },
  "updated_at": "2026-03-10T15:30:00.000Z"
}
```

### 3. sector-watch.json
存储关注板块列表：

```json
{
  "watch_list": [
    "云计算",
    "半导体",
    "游戏",
    "新能源"
  ]
}
```

## 五、API接口

### 1. 获取板块配置
```
GET /api/sector/profile
```

**返回**：
```json
{
  "groups": {
    "半导体": "硬件"
  },
  "custom_groups": ["资源", "硬件", "软件"],
  "etf_bindings": {
    "半导体": "sh512480"
  },
  "updated_at": "2026-03-10T15:30:00.000Z"
}
```

### 2. 保存板块配置
```
POST /api/sector/profile
Content-Type: application/json

{
  "groups": {
    "半导体": "硬件",
    "游戏": "消费"
  },
  "custom_groups": ["资源", "硬件", "软件", "消费"],
  "etf_bindings": {
    "半导体": "sh512480",
    "游戏": "sh516010"
  }
}
```

**功能**：
- 保存分类关系到 `sector-profile.json`
- 同步ETF绑定到 `sector-proxy.json`

### 3. 验证ETF代码
```
GET /api/sector/verify-etf?code=sh512480
```

**返回（有效）**：
```json
{
  "valid": true,
  "code": "sh512480",
  "count": 525,
  "start_date": "2024-01-02",
  "warning": null
}
```

**返回（数据不足）**：
```json
{
  "valid": true,
  "code": "sh563530",
  "count": 74,
  "start_date": "2024-11-25",
  "warning": "数据不足300天"
}
```

**返回（无效）**：
```json
{
  "valid": false,
  "code": "invalid",
  "error": "格式错误，应为 sh/sz + 6位数字"
}
```

### 4. 管理关注列表
```
GET /api/sector/watch-list        // 获取关注列表
POST /api/sector/watch-list       // 更新关注列表
```

## 七、使用流程示例

### 添加新板块

1. 打开"板块管理"
2. 添加分类（如"医疗"）
3. 在"添加板块"区域：
   - 输入名称：`医疗`
   - 输入ETF：`512480`（自动补全为 `sh512480`）
   - 选择分类：`医疗`
   - 点击"🔍验证" → 显示"✅ 有效，数据525天"
   - 点击"添加"
4. 点击"保存配置"

### 修改板块ETF

1. 在"已关注板块"找到目标板块
2. 修改ETF代码输入框
3. 点击"🔍验证"
4. 点击"保存配置"

## 八、注意事项

1. **ETF代码前缀**：系统会自动补全，但建议输入完整代码
2. **数据验证**：ETF必须至少有1天数据，建议≥300天
3. **同步保存**：修改后必须点击"保存配置"才能生效
4. **分类删除**：删除分类会清除该分类下所有板块的分类关系
5. **数据源**：ETF数据来自东财接口（AkShare），支持前复权

## 九、故障排查

### 验证失败
- **错误提示**："格式错误"
- **原因**：代码不是6位数字
- **解决**：检查代码位数，应为6位

### 验证失败
- **错误提示**："无数据"
- **原因**：ETF代码不存在或数据源无数据
- **解决**：确认ETF代码是否正确，或尝试其他代码

### 数据不足
- **警告提示**："数据不足300天"
- **影响**：仍可使用，但历史数据较短
- **解决**：等待数据积累，或选择其他ETF

### 保存失败
- **错误提示**："保存失败"
- **原因**：网络问题或服务器错误
- **解决**：刷新页面重试，检查服务器状态
