# M1 Quant Dashboard: 前端 UI 设计与功能架构文档

## 一、 视觉基调与空间布局 (Aesthetic & Layout)

### 1. 核心设计语言 (Tone: Refined & Minimalist)
*   **极简透气**：采用专业量化终端的亮色主题 (`#F8FAFC` 背景，`#FFFFFF` 卡片)。摒弃大面积色块与阴影，采用极细的 1px 分割线，克制地使用红绿双色（涨跌）。
*   **字体层级**：数字强制使用紧凑型等宽字体（如 `JetBrains Mono`），中文使用 `Inter/PingFang`。

### 2. 空间结构：左侧极简导航 + 独立工作区
放弃顶部 Tab，采用固定的左侧导航栏，右侧为独立的工作区，各页面的 AI 解读在其专属工作区内顶部呈现。

```text
+------+-----------------------------------------------------------------------+
| 导航 |  [页面 1: 盘中概览] 或 [页面 2: ETF 行情] 等工作区                            |
| [L]  |                                                                       |
| [O]  |  +-----------------------------------------------------------------+  |
| [G]  |  | 🧠 专属 AI 实时盘面解读 (带圆形仓位建议仪表盘)                     |  |
| [O]  |  +-----------------------------------------------------------------+  |
|      |                                                                       |
|  概  |  [主体数据图表与列表区，横向铺满]                                           |
|  览  |                                                                       |
|      |                                                                       |
|  行  |                                                                       |
|  情  |                                                                       |
+------+-----------------------------------------------------------------------+
```

## 二、 页面功能架构明细 (Feature Directory)

### 📌 页面 1：盘中概览 (Overview)
**定位**：聚焦大盘宏观走势、市场情绪与宽基/债券/金融表现。

```text
├── 🧠 顶部 AI 专区：大盘宏观解读 (Macro AI Summary)
│   ├── [左侧 1/4] 仓位建议仪表盘 (Gauge Chart)
│   │   └─ 醒目的半圆环形仪表盘，直观展示当前建议仓位（如：空仓 0% -> 满仓 100%）。
│   ├── [右侧 3/4] 智能投顾文字流与控制台
│   │   └─ 展示大盘走势判断、支撑位等大段复盘文本，附带 Prompt 调试按钮。
│
├── 📊 第一排：市场基建与情绪
│   ├── [左侧 1/3] 大盘情绪进度条 (红绿平涨跌家数)
│   └── [右侧 2/3] 成交额对比折线图 (将全市场成交额/ETF成交额/占比作为图例展示)
│
└── 📈 第二排：核心资产分时矩阵 (Compact Grid)
    ├── [核心宽基] 上证/深证/创业板/科创50/沪深300/中证1000
    ├── [国债市场] 30年国债ETF (`sh511130`) / 10年国债ETF (`sh511260`)  <-- 债券在此呈现
    └── [金融板块] 银行/证券/保险 (预留位置)
```

---

### 📌 页面 2：ETF 行情 (Market)
**定位**：专注 9 个核心行业/主题 ETF 的量价分析与轮动。

```text
├── 🧠 顶部 AI 专区：板块轮动解读 (Sector AI Summary)
│   ├── [左侧 1/4] 主线强度/进攻建议仪表盘 (Gauge Chart)
│   │   └─ 醒目的仪表盘，展示当前板块赚钱效应或进攻仓位建议。
│   ├── [右侧 3/4] 智能投顾文字流与控制台
│   │   └─ 专注解读板块轮动、跷跷板效应及主线逻辑。
│
├── 📉 第一排：任意板块行情与关联分析 (Correlation Analysis)
│   ├── [控制台] 输入框 + 周期切换 (当日/5日/30日/60日)
│   └── [图表区] ECharts 多线对比折线图 (归一化相对收益)
│
├── 🔲 第二排：60日上涨周期矩阵 (60-day Rotation Grid)
│   └── [高密度网格表] 纵轴为 ETF，横轴为过去 60 日，色块标注连涨天数。
│
└── 🚦 第三排：ETF 生命周期监测 (Lifecycle Dashboard)
    └── [按 3 大类横向分组的高密度列表]
        ├── 🟢 【建仓 / 持有池】(Buy/Hold)
        ├── 🟡 【震荡 / 观望池】(Wait/Observe)
        └── 🔴 【高位 / 离场池】(Sell/Risk)
```

## 三、 架构设计亮点
1. **AI 解读的页面级解耦**：大盘概览专注“宏观走势与总仓位”，ETF 行情专注“板块轮动与主线挖掘”。两者拥有独立的 Prompt 控制台与专属仪表盘。
2. **仪表盘视觉中心 (Gauge)**：将原本枯燥的文本“建议仓位”转化为 ECharts 的仪表盘（Gauge），作为进入每个页面的视觉锚点，瞬间传递最重要的决策信号。
3. **债券与宽基同列**：在概览页，将 30年/10年国债与上证等宽基并列展示，直观呈现“股债跷跷板”效应。
