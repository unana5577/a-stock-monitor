# M1 Quant Dashboard - 迭代开发任务拆解

## 阶段一：骨架与基础导航 (✅ 已完成)
*   **任务 1.1**：重写 `index_m1.html` 的基础 DOM 结构，实现**左侧固定侧边栏导航**（包含 Logo、盘中概览、板块行情等菜单）。
*   **任务 1.2**：实现右侧主体区域的布局，并用 Tailwind CSS 建立全局的颜色、字体变量（亮色主题 `#F8FAFC`）。
*   **验证标准**：页面可以正常点击左侧菜单切换右侧的空视图，视觉风格干净明亮。

## 阶段二：盘中概览页 - 核心重构 (✅ 已完成)
*   **任务 2.1**：搭建顶部 AI 专区布局。左侧嵌入 ECharts 的半圆形 Gauge（仓位建议仪表盘），右侧预留 AI 解读文本流。
*   **任务 2.2**：实现第一排“大盘情绪进度条（红绿平）”与“全市场成交额折线图（含总额/ETF占比）”。
*   **任务 2.3**：重写第二排的分时图矩阵。将 6大宽基 和 30年/10年国债ETF 用紧凑网格展示，并跑通底层的 ECharts 分时渲染逻辑。
*   **验证标准**：概览页数据全部打通，分时图红绿渐变清晰，仪表盘渲染成功。

## 阶段三：ETF 行情页 - 顶/中部分 (✅ 已完成)
*   **任务 3.1**：顶部 AI 专区。左侧为赚钱效应仪表盘，右侧为板块轮动解读文本流。
*   **任务 3.2**：复刻“任意板块行情与关联分析”组件。实现输入框样式与下方的多线归一化对比折线图（读取 M1 Warmup 渲染）。
*   **任务 3.3**：搭建“60日上涨周期”网格结构（暂时用假数据或空白占位，确保样式高度紧凑）。
*   **验证标准**：折线图能画出多条走势，网格表格排版不溢出、不凌乱。

## 阶段四：ETF 行情页 - 底部生命周期重构 (✅ 已完成)
*   **任务 4.1**：抛弃旧版大卡片，设计高信息密度的横向 List/Table。
*   **任务 4.2**：实现 Vue 逻辑，将 11 个 ETF 强制按照“建仓/持有”、“震荡/观望”、“高位/离场”三大状态池进行分组渲染。
*   **验证标准**：一眼扫清哪些能买哪些该卖，数据对齐准确无误。

## 阶段五：数据联动与最终联调
*   **任务 5.1**：接通所有真实 API（Overview、Minute、Breadth）。
*   **任务 5.2**：实现全局 60 秒定时自动无感刷新。
*   **验证标准**：挂机运行 10 分钟，内存不泄漏，图表平滑更新，终端无报错。
