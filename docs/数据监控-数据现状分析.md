**后端**（`server.js`）：
```javascript

  star: 'sh000680',   // 科创指数
};
```

**API端点**：`GET /api/minute/{code}`

### 💾 数据缓存位置

**实时分时数据**：
- 文件路径：`data/minute/runtime-YYYYMMDD-{code}.jsonl`
- 例如：`data/minute/runtime-20260415-sh000001.jsonl`

**历史分时数据**：
- 文件路径：`data/minute/minute-YYYYMMDD.jsonl`
- 按日期分片存储

**日线数据**：
- 文件路径：`data/index_daily/index_000001.jsonl`
- 当前状态：✅ 存在

### 🎯 可以把分时最后一条写入日线吗？

**答案：可以！**

**实现方案**：
1. 监控脚本检查实时分时文件 `data/minute/runtime-YYYYMMDD-{code}.jsonl`
2. 读取最后一条记录
3. 聚合成日线数据（open=第一分钟, high=最高价, low=最低价, close=最后分钟价格）
4. 追加写入 `data/index_daily/index_{code}.jsonl`

**注意事项**：
- ⚠️ 需要字段映射：分时字段 → 日线字段
- ⚠️ 成交量需要累加：`volume = sum(每分钟成交量)`
- ⚠️ 成交额需要累加：`amount = sum(每分钟成交额)`
