## 一、概述

### 1.1 目标

为A股量化软件（或自用分析工具）重新设计板块生命周期判断系统，通过**动态基准 + 动能 + 量价行为 + K线形态**四大核心要素，帮助用户识别板块状态，并给出3-5天的操作建议。系统将先从行业ETF入手，验证逻辑后再扩展至真实板块指数和个股。

### 1.2 核心逻辑

```
动态基准选择 → 动能判断（Alpha_5 70分位） → 量价行为 → K线形态 → 操作建议
   (基准)        (成长性)                (资金动向)   (信号确认)   (最终决策)
```

**关键原则**：
- **操作建议**由「动能 + 量价行为 + K线形态」决定
- **MA20（中期趋势）**仅作为显示信息，不影响操作建议
- **市场情绪过滤**和**风险评估**标记为后期扩展

### 1.3 适用范围

| 场景 | 说明 |
|------|------|
| 行业ETF分析 | **第一阶段目标**，跑通逻辑 |
| 板块指数分析 | 第二阶段扩展，需调整数据源和阈值 |
| 个股分析 | 未来复用，需单独调整阈值 |

### 2.4 数据管理规范

#### 2.4.1 文件命名格式
`{symbol}_{start_date}_{end_date}_{source}.parquet`
示例：`半导体ETF_20250519_20260305_sina.parquet`

#### 2.4.2 元数据要求
每个数据文件同级存放一个同名 `.json` 文件，记录：
- `source`：数据源（如 sina, akshare）
- `fetch_time`：拉取时间（ISO 格式）
- `fields`：字段说明（如 {"open": "开盘价", "close": "收盘价"}）
- `adjust_type`：复权类型（前复权/后复权/不复权）
- `calendar`：交易日历版本（如 "SSE"）

#### 2.4.3 更新策略
- **日常更新**：每日收盘后增量更新（追加当日数据）
- **非交易日处理**：回测时直接跳过非交易日，不填充数据
- **数据对齐**：所有时间序列按交易日对齐

## 四、动态基准选择（阶段1）

### 4.1 选择逻辑

| 步骤 | 说明 |
|------|------|
| 1 | 获取板块（ETF）过去60日收盘价序列 |
| 2 | 获取4个基准指数（上证、深证、创业板、科创板）60日收盘价序列 |
| 3 | 计算板块与每个指数的皮尔逊相关系数 |
| 4 | 选择相关系数最高的指数作为该板块的基准 |

### 4.2 输出字段

| 字段 | 示例 |
|------|------|
| 基准指数 | 创业板 |
| 相关性 | 0.85 |

### 4.3 后续使用及规则

所有 Alpha 计算都基于动态选择的基准。**重算频率与冻结规则**如下：

- **重算频率**：每月第一个交易日重新计算一次基准指数（基于过去60日数据）。期间保持不变，以保证稳定性
- **回测冻结规则**：在回测时，对于任意交易日 T，使用的基准必须是基于 **T-60 日至 T-1 日**的数据计算得出的，即只能用历史已知信息，严禁引入未来数据
- **实盘应用**：当日实时计算时，使用最近一次重算的基准（即本月基准），不实时切换

## 五、动能判断（阶段2）

### 5.1 动能判断（成长性）

**判断依据**：Alpha_5 分位数（70%分位）
**目的**：判断板块（ETF）的短期成长性和超额收益能力

| Alpha_5 分位数 | 动能判断 | 含义 |
|----------------|---------|------|
| > 70% | **强势** | 成长性好，跑赢大盘 |
| 50%~70% | **偏强** | 相对较强 |
| < 50% | **弱势** | 相对较弱 |

**实现**：
```python
if alpha_5_q > 0.7:
    momentum = "强势"
elif alpha_5_q > 0.5:
    momentum = "偏强"
else:
    momentum = "弱势"
```

**【阈值说明】**：
- Alpha_5 的分位数基于过去60日滚动窗口计算
- 70%分位数表示当前Alpha_5大于过去60日中70%的时期
- 每个ETF独立计算自身分位数，实现分板块动态阈值

## 六、操作建议生成（阶段3）【简化版】

本节采用**简化版方案**：通过**动能（Alpha_5）+ 量价行为 + K线形态**三大核心要素生成操作建议。

### 6.1 核心判断要素

#### 6.1.1 动能判断（成长性）

**目的**：判断板块（ETF）的短期成长性和超额收益能力

**判断依据**：Alpha_5 分位数（70%分位）

| Alpha_5 分位数 | 动能判断 | 含义 |
|----------------|---------|------|
| > 70% | **强势** | 成长性好，跑赢大盘 |
| 50%~70% | **偏强** | 相对较强 |
| < 50% | **弱势** | 相对较弱 |

#### 6.1.2 量价行为（资金动向）

**目的**：判断短期资金的进出行为

**判断依据**：3日均量比 + 涨跌幅

| 量比（Amount/MA3） | 涨跌幅（Pct） | 资金行为 | 含义 |
|-------------------|---------------|---------|------|
| > 1.3 | > 0 | **放量上涨** | 资金进场 |
| > 1.3 | < 0 | **放量下跌** | 资金出逃 |
| < 0.7 | 任意 | **缩量** | 观望/企稳 |
| 其他 | 任意 | **正常** | 横盘整理 |

**说明**：使用3日均量（MA3）而不是5日均量（MA5），更敏感

#### 6.1.3 K线形态（信号确认）

**目的**：识别单日K线形态，辅助判断多空力量对比

**判断逻辑**：

```python
def recognize_kline(open, close, high, low):
    """识别K线形态"""
    body = abs(close - open)
    if open == 0:
        return "普通K线"

    # 涨跌幅百分比
    body_pct = body / open * 100

    # 十字星：涨跌幅 < 1%
    if body_pct < 1.0:
        upper_shadow = high - max(open, close)
        lower_shadow = min(open, close) - low

        if lower_shadow > upper_shadow * 2:
            return "锤子线"  # 底部信号
        if upper_shadow > lower_shadow * 2:
            return "射击之星"  # 顶部信号
        return "十字星"  # 多空均衡

    # 大阳线/大阴线：涨跌幅 > 3%
    if body_pct > 3.0:
        return "大阳线" if close > open else "大阴线"

    # 小阳线/小阴线
    return "小阳线" if close > open else "小阴线"
```

**十字星的含义**：
- **强势动能**中出现十字星 → ⚠️ 谨慎观望，可能转折
- **弱势动能**中出现十字星 → ✅ 关注企稳，可能止跌

#### 6.1.4 中期趋势（MA20）- 仅显示

**目的**：展示中期趋势方向，**不作为操作建议的判断因子**

**判断依据**：MA20 斜率 + 价格位置

| MA20斜率 | 价格 vs MA20 | 趋势标签 |
|----------|-------------|---------|
| > 0 | Close > MA20 | 上升趋势 |
| < 0 | Close < MA20 | 下降趋势 |
| 其他 | 任意 | 横盘整理 |

**用途**：仅在界面展示，帮助用户理解整体状态

### 6.2 操作建议映射表

**核心逻辑**：动能 + 量价 + K线 → 操作建议

| 动能 | 量价行为 | K线形态 | 操作建议 | 说明 |
|------|---------|---------|----------|------|
| **强势** | 放量上涨 | 大阳线 | 持股待涨 | 主升阶段 |
| 强势 | 放量上涨 | 小阳线 | 持股待涨 | 健康上涨 |
| 强势 | 放量上涨 | 十字星 | 谨慎观望 | ⚠️ 可能转折 |
| 强势 | 放量下跌 | 任意 | 果断离场 | 资金出逃 |
| 强势 | 缩量 | 射击之星 | 分批止盈 | 涨幅过大 |
| 强势 | 正常 | 任意 | 持有观察 | 等待方向 |
| **偏强** | 放量上涨 | 大阳线 | 积极建仓 | 启动信号 |
| 偏强 | 放量上涨 | 小阳线 | 积极建仓 | 可以参与 |
| 偏强 | 放量下跌 | 任意 | 观望 | 谨慎 |
| 偏强 | 正常 | 任意 | 持有观察 | 等待确认 |
| **弱势** | 放量上涨 | 锤子线 | 抄底机会 | ⚠️ 风险高 |
| 弱势 | 放量上涨 | 任意 | 观望 | 反弹不确定 |
| 弱势 | 放量下跌 | 任意 | 观望 | 不参与 |
| 弱势 | 缩量 | 锤子线 | 关注企稳 | 可能止跌 |
| 弱势 | 正常 | 任意 | 观望等待 | 等待信号 |

**判断优先级**：
1. **放量上涨 + 强势** → 持股待涨
2. **放量下跌** → 果断离场
3. **十字星** → 谨慎观望/关注企稳
4. **放量上涨 + 偏强** → 积极建仓
5. **弱势** → 观望为主

### 6.3 实现示例

```python
def get_advice(momentum, fund_behavior, kline_type):
    """根据动能、资金行为、K线生成操作建议"""

    if momentum == "强势":
        if fund_behavior == "放量上涨":
            if kline_type == "十字星":
                return "谨慎观望"
            return "持股待涨"

        if fund_behavior == "放量下跌":
            return "果断离场"

        if fund_behavior == "缩量" and kline_type == "射击之星":
            return "分批止盈"

        return "持有观察"

    elif momentum == "偏强":
        if fund_behavior == "放量上涨":
            return "积极建仓"

        if fund_behavior == "放量下跌":
            return "观望"

        return "持有观察"

    else:  # 弱势
        if fund_behavior == "放量上涨" and kline_type == "锤子线":
            return "抄底机会"  # 风险高

        if fund_behavior == "放量下跌":
            return "观望"

        if fund_behavior == "缩量" and kline_type == "锤子线":
            return "关注企稳"

        return "观望等待"
```

## 七、回测框架与阈值优化（阶段4-5）

### 7.1 回测目标
- 验证判断逻辑的有效性
- 调优各阈值参数（分ETF独立优化，采用分位数法）
- 评估不同市场状态下的表现

### 7.2 回测配置

| 项目 | 说明 |
|------|------|
| 起始日期 | 2025-05-19 |
| 回测频率 | 每日 |
| 预测周期 | 3日、5日 |
| 评价指标 | 准确率（未来N日涨跌与建议方向一致的比例）、各建议准确率、胜率、平均收益 |

### 7.3 准确率定义（针对不同建议）

| 操作建议 | 正确标准（未来3日） |
|----------|----------------------|
| 持股待涨、积极建仓 | 涨幅 > 0（或 > ETF自身波动率阈值） |
| 分批止盈、逐步减仓 | 出现冲高回落（最高点 > 入场价5%但收盘回落）或跌幅 > 2% |
| 果断离场 | 跌幅 > 2% |
| 观望、等待 | 不设定正误，或定义为波动在±2%内 |

### 7.4 阈值优化方法

1. **分位数法**：对每个 ETF，统计各指标（Alpha_5等）的历史分布（建议用滚动60日窗口），计算 50%、70%、80% 分位数作为阈值边界
2. **映射规则**：将原判断逻辑中的绝对值条件替换为分位数条件（如 Alpha_5 > 70% 对应"强势"）
3. **分ETF独立配置**：每个ETF生成一套独立的阈值配置文件（如 `config_etf.py`）

### 7.5 输出报告
- 总体准确率
- 各信号准确率
- 各ETF准确率
- 胜率、平均收益

- 引入全市场成交额 MA5、涨跌家数比、连板高度等
- 定义市场状态：强势上涨/震荡/下跌/恐慌
- 作为顶层过滤器：市场恐慌时，所有买入建议降级或过滤

### 9.2 初步交易策略（阶段8）
- 实现简单的状态机管理持仓
- 定义信号到开平仓动作的映射
- 模拟交易，计算收益率曲线、夏普比率、最大回撤

### 9.3 新闻因子（阶段9）
- 获取板块相关新闻标题，用情感分析打分（-2~+2）
- 作为修正因子，调整操作建议置信度或直接升降级
- 需解决未来函数问题（确保新闻时间与K线对齐）

### 9.4 扩展因子（阶段9）
- 北向资金净流入
- 融资余额变化
- 美股映射（相关指数隔夜涨跌）

### 9.5 从ETF过渡到板块/个股（阶段10）
- 替换数据源为真实板块指数（如申万二级行业）
- 重新优化阈值
- 支持个股（需单独调整阈值）

## 十一、技术要点

### 11.1 文件结构

```
a-stock-monitor/
├── data/                         # 原始数据存放
│   ├── etf_daily/                # ETF日线数据
│   ├── index_daily/              # 指数日线数据
│   └── market/                   # 全市场数据
├── sector_lifecycle/              # 核心逻辑包
│   ├── __init__.py
│   ├── indicators.py             # 指标计算
│   ├── benchmark.py              # 动态基准选择
│   ├── momentum.py               # 动能判断（Alpha_5 70分位）
│   ├── fund_behavior.py          # 资金行为判断（量价+K线）
│   ├── kline.py                  # K线形态识别
│   ├── advice.py                 # 操作建议生成
│   └── config.py                 # 阈值配置
├── backtest/                      # 回测相关
│   ├── backtest_engine.py        # 回测引擎
│   └── report.py                 # 报告生成
├── web/                           # 前端及API
│   ├── server.js                  # API服务
│   └── public/
│       └── index.html             # 前端页面
└── docs/                          # 文档
    └── plans/2026-03-06-新版.md   # 本需求文档
```

### 11.2 关键注意事项
- **数据对齐**：确保所有时间序列按交易日对齐，无缺失
- **未来函数**：回测中严格避免使用未来数据（如计算历史极值时，只能用截止当天的数据）
- **信号重叠**：在未实现交易策略前，仅评价单日信号；实现交易策略后，需定义状态机处理连续信号
- **阈值动态化**：阈值应定期（如每月）基于最新历史数据重新计算分位数，以适应市场变化。回测时则按当时已知信息计算
