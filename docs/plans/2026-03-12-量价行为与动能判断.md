### 4.3 基准指数对比（相对强度）

**计算**：相对强度 = ETF涨跌幅 - 基准涨跌幅

**基准选择**：动态选择相关性最高的基准（上证/深证/创业板/科创板）

**回测窗口**：60日滚动窗口（统一使用60天）

**相��性阈值**：**60%** ✅（已实现验证）
- **相关性 ≥ 60%**：使用相对强度判断
- **相关性 < 60%**：独立行情，只用量价行为判断（不使用相对强度）

**相对强度判断**：**直接比较**（无阈值）
- **ETF涨跌幅 > 基准涨跌幅**：强于大盘（跑赢）
- **ETF涨跌幅 < 基准涨跌幅**：弱于大盘（跑输）
- **ETF涨跌幅 = 基准涨跌幅**：与大盘持平

**独立行情识别**：
- **定义**：ETF与所有基准的相关性都低于60%
- **原因**：该ETF走出独立行情，不受大盘影响
- **处理**：量价行为判断时不使用相对强度（所有"强于大盘/弱于大盘"改为"与大盘持平"）
- **示例**：创新药ETF（相关性0.23-0.27，独立行情）

## 五、风险与位置（乖离率）

**目的**：判断风险等级

### 5.1 乖离率定义

**乖离率（Bias）**：衡量价格偏离移动平均线的程度

**5日乖离率（Bias_5）计算公式**：
```
Bias_5 = (当前价格 - MA5) / MA5 × 100%
```

**含义**：
- Bias_5 > 0：价格高于5日均线（正乖离）
- Bias_5 < 0：价格低于5日均线（负乖离）
- 数值越大，偏离程度越大

**特点**：
- 反应灵敏，适合短期波段操作
- 正乖离过大：风险累积
- 负乖离过大：可能机会，也可能继续下跌

### 5.2 动态阈值（自身历史分位数）

**核心思想**：每个ETF根据自身过去60天的Bias_5分布，计算不同的风险阈值

**计算方法**：
1. 计算每日Bias_5
2. 使用60日滚动窗口，计算分位数
3. 得到动态阈值：95%、80%、60%、40%、20%、5%分位

**特点**：
- 每个ETF独立计算，互不影响
- 自动适应不同ETF的波动特性
- 无需人工分类或调整阈值

**数据来源**：每个ETF自己的历史数据（60日滚动窗口）

### 5.3 乖离率风险等级

**核心思想**：乖离率只判断风险，不判断机会

| 风险等级 | Bias_5分位 | 描述 | 操作建议 |
|---------|-----------|------|---------|
| 极度风险 | > 95% | 严重超涨，顶部信号 | 立即离场，禁止追涨 |
| 高风险 | 80%-95% | 明显超涨，接近顶部 | 逐步减仓，锁定利润 |
| 中高位风险 | 60%-80% | 偏高，加速期 | 谨慎持有，关注量价 |
| 中位风险 | 40%-60% | 正常波动 | 观望 |
| 中低位风险 | 20%-40% | 偏低 | 观望 |
| 低风险 | 5%-20% | 超跌 | 结合量价判断 |
| 极度超跌 | < 5% | 严重超跌 | 结合量价判断 |

**判断逻辑**：
1. 计算当前Bias_5
2. 获取该ETF的60日滚动分位数（95%/80%/60%/40%/20%/5%）
3. 对比判断风险等级

**重要说明**：
- 乖离率 > 0（正乖离）：偏离均线向上，风险逐渐增大
- 乖离率 < 0（负乖离）：偏离均线向下，可能是机会也可能继续下跌
- **只有量价行为才能判断是否是机会**
- 量价有单独的判断逻辑（第四节），最后会整合量价+乖离率进行综合判断

**示例**：
- 机器人ETF当前Bias_5 = 2.57%，60日滚动分位数：95%=6.2%, 80%=4.1%, 60%=2.5%, 40%=0.8%, 20%=-1.2%, 5%=-3.5%
- 判断：2.57% > 60%分位(2.5%)，处于"中高位风险"区间

## 六、综合操作指导

**核心思想**：将量价行为、乖离率、K线形态三个独立判断系统整合成一个统一的操作建议系统。

### 6.1 三层过滤框架

**三层过滤逻辑**：
```
第一层：乖离率（风险过滤器）
   ↓
第二层：量价行为（机会探测器）
   ↓
第三层：K线形态（转折确认器）
```

**各层作用**：
- **第一层（乖离率）**：判断风险等级，排除高风险区域
- **第二层（量价行为）**：判断资金流向，寻找入场机会
- **第三层（K线形态）**：确认关键转折点，提高信号准确性

### 6.2 综合判断流程

#### 步骤1：乖离率判断风险等级

**目的**：排除高风险区域，只在中低风险区域寻找机会

| 当前风险等级 | 是否可以参与 | 说明 |
|-------------|-----------|------|
| 极度风险、高风险 | ❌ 禁止参与 | 风险>收益，只卖不买 |
| 中高位风险 | ⚠️ 谨慎参与 | 只减不加，关注量价确认 |
| 中位风险 | ✅ 可以参与 | 观望为主，等待量价信号 |
| 中低位风险 | ✅ 积极参与 | 关注量价信号 |
| 低风险、极度超跌 | ✅ 积极参与 | 重点寻找机会 |

**输出**：风险等级 + 是否可以参与

#### 步骤2：量价行为判断资金流向

**目的**：在中低风险区域，判断是否有资金进场

**判断逻辑**：
```
IF 量价行为 = "放量强势上涨" AND 相对强度 = "强于大盘"
  → 强力买入信号
ELSE IF 量价行为 = "放量抗跌" AND 相对强度 = "强于大盘/持平"
  → 可能企稳，关注
ELSE IF 量价行为 = "缩量强势上涨" AND 相对强度 = "强于大盘"
  → 惜售但强势，观察
ELSE IF 量价行为 = "缩量抗跌"
  → 可能企稳，关注
ELSE
  → 观望
```

**特别注意**：
- **独立行情ETF**（相关性<60%）：相对强度为"持平"，只看量价
- **"放量强势上涨" + "弱于大盘"** = 虚涨，需谨慎

**输出**：资金行为判断（强势买入/可能企稳/观察/观望）

#### 步骤3：K线形态确认转折点

**目的**：在量价信号基础上，用K线形态确认关键转折

**K线基础形态**：
- **十字星**：实体<1%
- **锤子线**：底部 + 长下影线（通常下影线≥2倍实体）
- **射击之星**：顶部 + 长上影线（通常上影线≥2倍实体）
- **大阳线/大阴线**：涨跌幅>3%

**底部确认信号**（组合条件）：
- 乖离率：低风险或极度超跌（<20%分位）
- 量价行为：放量抗跌 OR 缩量抗跌
- K线形态：底部十字星 OR 锤子线
- 次日：放量上涨
→ **操作建议：分批建仓**

**顶部确认信号**（组合条件）：
- 乖离率：极度风险或高风险（>80%分位）
- 量价行为：放量下跌 OR 放量滞涨
- K线形态：顶部十字星 OR 射击之星
- 次日：放量下跌
→ **操作建议：清仓离场**

**K线与量价配合**：
- **底部十字星** + 次日放量上涨 → 企稳确认
- **顶部十字星** + 次日放量下跌 → 见顶确认
- **多个十字星** → 持续震荡，方向不明

**输出**：转折点确认（底部确认/顶部确认/无确认）

### 6.3 操作建议分级

基于三层过滤的结果，给出明确的操作建议：

| 操作建议 | 满足条件 | 具体说明 |
|---------|---------|---------|
| **强力买入** | 低风险/极度超跌 + 放量强势上涨 + 强于大盘 | 资金强力进场，风险低 |
| **买入** | 中低位风险 + 放量强势上涨 + 强于大盘 | 有资金进场，风险可控 |
| **观察** | 中位风险 + 任意量价行为 | 等待明确信号 |
| **谨慎持有** | 中高位风险 + 缩量强势上涨 + 强于大盘 | 有利润但需谨慎 |
| **减仓** | 高风险 + 放量下跌/放量滞涨 | 风险增大，锁定利润 |
| **清仓** | 极度风险 + 放量下跌 + 顶部K线 | 立即离场 |
| **观望** | 其他组合 | 等待明确信号 |

**仓位管理原则**（基于乖离率分位）：
- **高位（>80%分位）**：风险>收益，只减不加
- **中位（40%-80%分位）**：持有为主，关注量价变化
- **低位（<40%分位）**：机会>风险，可分批建仓
