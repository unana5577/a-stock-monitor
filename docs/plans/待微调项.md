### 2. 原因表述整合 📝
**问题**：当前原因表述过于分散，缺乏整体性

**当前示例**：
```

```

**改进方向**：整合为更完整的表述，参考之前的逻辑：
- **偏强向上**：短期+中期趋势都向上，资金放量
- **跌势加剧**：短期+中期趋势都向下，且斜率较大
- **企稳迹象**：低位+放量+斜率转正
- **空仓观望**：高风险或缩量+趋势不明

**实现方式**：
- 在 `generate_advice()` 函数中，根据多个指标组合生成更完整的原因表述
- 不再只是简单的"关注企稳机会"，而是描述整体状态
- 加入仓位建议：空仓观望、轻仓试水、半仓、减仓等
