## 一、核心框架

### 1.1 展示指标（仅供参考）

| 指标 | 公式 | 强弱判断 |
|------|------|---------|
| Alpha_5 | ETF5日涨幅 - 基准5日涨幅 | >0跑赢(强), <0跑输(弱) |
| Alpha_20 | ETF20日涨幅 - 基准20日涨幅 | >0跑赢(强), <0跑输(弱) |

**强弱细分**：
- Alpha > 3%：显著强势 ✅
- 0% < Alpha ≤ 3%：小幅强势
- -3% ≤ Alpha < 0：小幅弱势
- Alpha < -3%：显著弱势 ❌

### 1.2 判断指标（用于决策）

| 指标 | 公式/来源 | 用途 |
|------|----------|------|
| 大盘情绪 | ai.js（进攻/防御/震荡） | 顶层过滤 |
| 趋势 | MA5_Slope | 方向判断 |
| 量能 | 资金热度 = ETF成交额 / (市场成交额×20%) | 资金行为 |
| 乖离率 | Bias_5分位数 | 风险等级 |

## 二、判断指标详解

### 2.1 大盘情绪（复用ai.js）

```
来源：ai.js 的 analyze() 函数
输入：上证指数pct、科创50pct、成交量
输出：
- 进攻：资金情绪积极，成长风格占优
- 防御：避险情��升温，注意风险控制
- 震荡：市场窄幅震荡，方向不明

调用方式：
- 方式1：直接调用 ai.js
  const ai = require('./ai');
  const result = ai.analyze(payload);

- 方式2：通过API获取
  fetch('/api/snapshot/latest?ai=1')
```

### 2.2 动态基准选择

```
目的：为每个ETF选择最相关的基准指数

基准候选：
- 上证指数（sh000001）
- 深证成指（sz399001）
- 创业板指（sz399006）
- 科创50（sh000680）

选择逻辑：
1. 获取ETF过去60日收盘价序列
2. 获取4个基准指数过去60日收盘价序列
3. 计算ETF与每个指数的皮尔逊相关系数
4. 选择相关系数最高的指数作为该ETF的基准

重算频率：每月第一个交易日重算一次（保持稳定性）

输出格式：
{
  "etf_code": "515880",
  "benchmark": "sz3006",  // 创业板指
  "correlation": 0.85,
  "updated": "2026-03-01"
}
```

### 2.3 趋势

```
指标：MA5_Slope
公式：MA5_Slope = (MA5 - MA5_3日前) / MA5_3日前 × 100%

判断：
- 上升趋势：MA5_Slope > 0
- 下降趋势：MA5_Slope < 0
- 横盘整理：其他
```

### 2.4 量能（资金热度）

```
核心指标：Amount_Share = ETF成交额 / (市场成交额 × 20%)
变化比例：Amount_Share_Change = 今日Amount_Share / 昨日Amount_Share

判断：
- 放量：Amount_Share_Change > 1.1
- 缩量：Amount_Share_Change < 0.9
- 持平：其他

说明：市场成交额暂用概览页的"全市场成交额"，ETF占比按20%计算
```

### 2.5 乖离率（风险等级）

```
指标：Bias_5
公式：Bias_5 = (close - MA5) / MA5 × 100%

风险等级（基于60天滚动分位数）：
- 极度风险：> 95%分位
- 高风险：80%-95%分位
- 中高位风险：60%-80%分位
- 中位风险：40%-60%分位
- 中低位风险：20%-40%分位
- 低风险：5%-20%分位
- 极度超跌：< 5%分位
```

### 3.1 完整映射表

| 风险等级 | 资金热度 | 趋势 | 操作建议 | 说明 |
|---------|---------|------|----------|------|

| **高风险** | 任意 | 任意 | 逐步减仓 | 锁定利润，防范回调 |
| **中高位风险** | 放量 | 向上 | 小仓位试水 | 风险适中+资金进场 |
| 中高位风险 | 放量 | 向下 | 观望 | 等待企稳信号 |
| 中高位风险 | 缩量 | 任意 | 观望 | 缺乏资金支持 |
| **中位风险** | 放量 | 向上 | 小仓位试水 | 趋势向上+资金确认 |
| 中位风险 | 放量 | 向下 | 观望 | 等待方向明确 |
| 中位风险 | 缩量 | 任意 | 观望 | 缩量震荡，等待突破 |
| **中低位风险** | 放量 | 向上 | 小仓位试水 | 风险较低+资金进场 |

| 中低位风险 | 缩量 | 向上 | 继续观察 | 等待放量确认 |
| 中低位风险 | 缩量 | 向下 | 继续观察 | 等待企稳信号 |
| **低风险** | 放量 | 向上 | 关注企稳/试水 | 低位+资金进场，关注机会 |
| 低风险 | 放量 | 向下 | 关注企稳 | 关注企稳信号 |
| 低风险 | 缩量 | 任意 | 继续观察 | 等待资金进场 |
| **极度超跌** | 放量 | 任意 | 关注企稳/抄底 | 超跌+资金进场，关注反弹 |
| 极度超跌 | 缩量 | 任意 | 等待放量 | 等待底部信号 |

### 3.2 核心规则总结

```
1. 极度风险/高风险 → 减仓/离场（不管其他条件）
2. 极度超跌 + 放量 → 关注企稳/抄底（超跌反弹）
3. 其他情况：
   - 放量 + 向上 → 小仓位试水（风险可控+资金确认）
   - 放量 + 向下 → 观望/关注（可能企稳）
   - 缩量 + 任意 → 继续观察（缺乏资金）
```

### 7.2 趋势标签（tag）计算逻辑

**计算位置**：前端（基于昨日和今日涨跌幅）

```
修复转强：昨日 ≤ -1% 且 今日 ≥ 0.5%
转强：昨日 < 0 且 今日 > 0
转弱：昨日 > 0 且 今日 < 0
今日强势：今日 ≥ 1%
跌势收敛：都跌但今日跌幅小于昨日（n > y）
跌势加剧：都跌且今日跌幅大于昨日（n < y）
今日走弱：今日 ≤ -1%
横盘：其他情况
```

### 7.3 动能（momentum）计算逻辑

**复用来源**：`sector_lifecycle.py` 第166-207行 `determine_momentum()` 函数

**输入参数**：
- `alpha_5`: 5日超额收益率（百分比）
- `ma5_slope`: MA5斜率
- `close`: 当前收盘价
- `ma5`: MA5均线值
- `alpha_5_q`: Alpha_5分位数（可选，简化版可先用绝对值）

**输出标签**：
- 强势向上
- 偏强向上
- 中性震荡
- 弱势向下
- 弱势反弹

**简化版判断逻辑**（不使用分位数）：
```
Alpha_5 > 3% 且 MA5斜率 > 0 且 收盘价 > MA5 → 强势向上
1% ≤ Alpha_5 ≤ 3% 且 MA5斜率 > 0 且 收盘价 > MA5 → 偏强向上
-1% ≤ Alpha_5 ≤ 1% → 中性震荡
Alpha_5 < -1% 且 MA5斜率 < 0 且 收盘价 < MA5 → 弱势向下
Alpha_5 < -1% 且 MA5斜率 > 0 且 收盘价 > MA5 → 弱势反弹
```

### 7.4 资金行为（behavior）计算逻辑

**复用来源**：`sector_lifecycle.py` 第210-253行 `determine_fund_behavior()` 函数

**输入参数**：
- `amount_share_pct`: 当前成交占比（ETF成交额/全市场ETF成交额）
- `amount_share_change`: 成交占比变化率（今日/昨日）
- `pct`: 日涨跌幅
- `bias_20`: 20日乖离率（可选）

**简化版判断逻辑**：
```
涨跌幅 < -3% 且 成交占比 > 历史80分位 → 恐慌出逃
涨跌幅 > 0 且 成交占比变化率 ≥ 0.5 → 放量启动
成交占比从近20日高点下跌 ≥ 20% → 资金撤退
20日乖离率 > 8 且 涨跌幅 > 0 → 加速赶顶
20日乖离率 < -8 且 涨跌幅 < 0 → 超跌反弹
其他 → 横盘整理
```

### 7.5 操作建议（action）计算逻辑 - 新增风险管理

**设计思路**：
简化版在sector_lifecycle.py原有逻辑基础上，**加入风险管理维度**，形成三维决策模型：
- **动能**（momentum）：趋势强度
- **资金行为**（behavior）：资金流向
- **风险等级**（risk_level）：乖离率风险

**核心原则**：
1. **极度风险/高风险** → 强制减仓/离场（不管动能和行为）
2. **极度超跌** → 关注抄底机会（超跌反弹）
3. **其他风险等级** → 根据动能+行为判断

**完整操作建议表**：

| 风险等级 | 动能 | 资金行为 | 操作建议 | 仓位指导 |
|---------|------|---------|---------|---------|
| **极度风险** | 任意 | 任意 | **减仓/离场** | 清仓 |
| **高风险** | 任意 | 任意 | **逐步减仓** | 减仓至半仓以下 |
| **极度超跌** | 弱势反弹 | 放量启动 | **关注企稳** | 轻仓试探 |
| **极度超跌** | 任意 | 其他 | **等待放量** | 空仓观望 |
| 中低位风险 | 强势向上 | 放量启动 | **积极建仓** | 半仓以上 |
| 中低位风险 | 偏强向上 | 放量启动 | **轻仓试探** | 轻仓（20%） |
| 中低位风险 | 中性震荡 | 放量启动 | **小仓埋伏** | 小仓（10%） |
| 中位风险 | 强势向上 | 放量启动 | **持股待涨** | 持有 |
| 中位风险 | 偏强向上 | 横盘整理 | **持有** | 持有 |
| 中位风险 | 任意 | 资金撤退 | **逐步减仓** | 减仓 |
| 中高位风险 | 强势向上 | 加速赶顶 | **分批止盈** | 减仓 |
| 中高位风险 | 弱势向下 | 恐慌出逃 | **果断止损** | 清仓 |
| 低风险 | 弱势向下 | 资金撤退 | **空仓观望** | 空仓 |
| 低风险 | 弱势反弹 | 超跌反弹 | **关注企稳** | 观望 |
| 其他 | 中性震荡 | 横盘整理 | **观望等待** | 观望 |

**仓位指导关键词说明**：
- **清仓**：0%仓位，完全离场
- **空仓观望**：0%仓位，等待信号
- **果断止损**：立即清仓，截断亏损
- **逐步减仓**：减仓至半仓或以下
- **分批止盈**：分批卖出，锁定利润
- **轻仓试探**：10-20%仓位，试探性建仓
- **小仓埋伏**：5-10%仓位，提前布局
- **积极建仓**：30-50%仓位，主动买入
- **持有**：维持当前仓位
- **持股待涨**：满仓或重仓，等待上涨
- **关注企稳**：0-10%仓位，观察等待
- **观望等待**：0%仓位，不操作
- **等待确认**：0%仓位，等待明确信号

**与前端对应**：
- 前端`action`字段直接显示操作建议
- 仓位指导隐含在操作建议中（如"轻仓试探"=轻仓，"空仓观望"=空仓）
- 风险等级不直接显示，但通过操作建议体现
