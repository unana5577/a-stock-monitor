# 麻烦的接口

## 1. 行业板块接口 - `stock_board_industry_name_em()`

### 功能
获取全市场行业板块数据，包含涨跌家数、板块涨跌幅、领涨股票等信息。

### 接口信息
```python
import akshare as ak

# 获取所有行业板块数据（东方财富）
board_df = ak.stock_board_industry_name_em()
```

### 返回字段
| 字段 | 说明 | 示例 |
|------|------|------|
| 排名 | 板块排名 | 1, 2, 3... |
| 板块名称 | 行业板块名称 | 长材、房产租赁经纪、期货... |
| 板块代码 | 板块代码 | BK1369, BK1341... |
| 最新价 | 板块指数最新价 | 702.90 |
| 涨跌额 | 涨跌额 | +27.95 |
| 涨跌幅 | 涨跌幅百分比 | +4.14% |
| 总市值 | 板块总市值 | - |
| 换手率 | 换手率 | 5.22% |
| **上涨家数** | 板块内上涨股票数量 | 3 |
| **下跌家数** | 板块内下跌股票数量 | 0 |
| 领涨股票 | 领涨股票名称 | 中南股份 |
| 领涨股票-涨跌幅 | 领涨股票涨跌幅 | +7.06% |

### 数据特点
- **板块数量**：约496个行业板块
- **更新频率**：实时（交易时间内）
- **数据来源**：东方财富网
- **请求耗时**：约4-5秒（需要分页请求69次）

### 计算全市场涨跌家数
```python
# 板块数据汇总统计
total_up = board_df['上涨家数'].sum()      # 总上涨家数
total_down = board_df['下跌家数'].sum()    # 总下跌家数
total = total_up + total_down              # 总计

# 涨跌比
ratio = total_up / total_down if total_down > 0 else float('inf')

# 情绪判断
sentiment = '亢奋' if ratio > 2 else ('恐慌' if ratio < 0.3 else '正常')
```

### 实测数据（2026-03-17）
```
上涨家数: 2664
下跌家数: 13758
总家数: 16422
涨跌比: 0.19
情绪: 恐慌
```

**问题**：数据与实际A股数量不符，可能包含重复统计或未覆盖全部股票。

## 2. A股实时行情接口 - `stock_zh_a_spot()`

### 功能
获取所有A股实时行情数据（沪深北全市场），包含股票最新价、涨跌幅、成交量等信息。

### 接口信息
```python

# 获取所有A股实时行情
stocks_df = ak.stock_zh_a_spot()
```

### 返回字段
| 字段 | 说明 | 示例 |
|------|------|------|
| 代码 | 股票代码 | bj920000, sh600000... |
| 名称 | 股票名称 | 安徽凤凰、浦发银行... |
| 最新价 | 最新成交价 | 17.06 |
| 涨跌额 | 涨跌额 | -0.35 |
| **涨跌幅** | 涨跌幅百分比 | -2.01% |
| 买入 | 买入价 | - |
| 卖出 | 卖出价 | - |
| 昨收 | 昨日收盘价 | 17.41 |
| 今开 | 今日开盘价 | 17.40 |
| 最高 | 今日最高价 | 17.60 |
| 最低 | 今日最低价 | 17.03 |
| 成交量 | 成交量 | 506687.0 |
| 成交额 | 成交额 | 8768151.0 |
| 时间戳 | 更新时间戳 | 15:30:00 |

### 数据特点
- **股票数量**：约5488只（沪深北全市场）
- **更新频率**：实时（交易时间内）
- **数据来源**：新浪财经
- **请求耗时**：约21秒（需要分页请求69次）
- **覆盖范围**：沪市、深市、北交所

### 计算全市场涨跌家数
```python
# 直接统计个股涨跌
up = stocks_df[stocks_df['涨跌幅'] > 0].shape[0]      # 上涨家数
down = stocks_df[stocks_df['涨跌幅'] < 0].shape[0]    # 下跌家数
flat = stocks_df[stocks_df['涨跌幅'] == 0].shape[0]   # 平盘家数

total = up + down + flat
ratio = up / down if down > 0 else float('inf')

# 情绪判断
if ratio < 0.3:
    sentiment = "恐慌"
elif ratio > 2.0:
    sentiment = "亢奋"
else:
    sentiment = "正常"
```

### 实测数据（2026-03-17 15:30收盘后）
```
上涨: 866
下跌: 4541
平盘: 81
总计: 5488
涨跌比: 0.19
市场情绪: 恐慌
```

**优势**：✅ 数据准确，覆盖全市场5488只股票

- ✅ 数据准确（5488只）
- ✅ 包含平盘家数
- ⚠️ 请求较慢（21秒）

**ETF成交额**：使用 `fund_etf_category_sina(symbol="ETF基金")`
- ✅ 实时数据
- ✅ 请求快速
- ✅ 数据准确

## 实现计划

### ETF成交额（每小时更新）
1. 创建Python脚本 `etf_amount_hourly.py`
2. 定时任务：每小时执行一次（crontab: `0 * * * *`）
3. 存储文件：`data/etf-amount-hourly.jsonl`
4. 字段：时间、总成交额、ETF数量

### A股涨跌家数（每分钟更新）
1. 创建Python脚本 `market_breadth_spot.py`
2. 集成到现有快照接口（`/api/snapshot/latest`）
3. 添加字段：
   ```json
   {
     "breadth": {
       "up": 866,
       "down": 4541,
       "flat": 81,
       "total": 5488,
       "ratio": 0.19,
       "sentiment": "恐慌"
     }
   }
   ```
4. 更新频率：每30秒（与快照一致）

## 注意事项

1. **请求频率限制**
   - `stock_zh_a_spot()` 耗时较长（21秒），不宜频繁请求
   - 建议缓存1-2分钟，避免重复请求

2. **交易时间判断**
   - 只在交易时间内更新数据
   - 收盘后使用最后一次快照数据

3. **数据持久化**
   - ETF成交额：按小时存储，用于历史分析
   - 涨跌家数：只存储当日快照，不保留历史

4. **错误处理**
   - 接口超时：使用缓存数据
   - 数据异常：记录日志，不阻塞主流程
