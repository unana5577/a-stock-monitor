## 一、成交额分时数据流程

```
┌─────────────────────────────────────────────────��───────────────┐
│                     成交额分时数据流程                           │
└─────────────────────────────────────────────────────────────────┘

【数据源】
  └─> 腾讯API (sh000001 + sz399001)
      ├─ 上证指数成交额：snaps['sh000001'].amount
      └─ 深证指数成交额：snaps['sz399001'].amount 或 snaps['sz399106'].amount

【实时获取】
  └─> server.js: buildSnapshotPayload()
      └─> 总成交额 = sh000001.amount + sz399001.amount
          代码位置：server.js:2899-2902

【定时保存】
  └─> server.js:4952-4971 (每30秒执行)
      ├─> 触发条件：isMarketOpenNow() = true (9:30-15:00)
      ├─> 文件路径：volumeFilePath(day) = data/volume-${YYYYMMDD}.json
      └─> 写入函数：appendVolumePoint(file, time, volume)

【文件格式】
  └─> data/volume-20260316.json
      [
        ["09:30", 12345678.9],  // [时间, 成交额(万元)]
        ["09:31", 23456789.0],
        ...
      ]

【使用场景】
  └─> 前端请求 /api/sentiment
      └─> readVolumeSeries(day) → 读取分时成交额
          └─> 返回当前累计、昨日全天、预估增量等
```

## 二、ETF日线数据流程

```
┌─────────────────────────────────────────────────────────────────┐
│                       ETF日线数据流程                            │
└─────────────────────────────────────────────────────────────────┘

【数据源】
  └─> AkShare Sina ETF专用接口
      └─> fund_etf_hist_sina(symbol=ETF代码)
          代码位置：fetch_sector_data.py:_fetch_akshare_sina_etf()

【自动检测】
  └─> fetch_sector_data.py:_fetch_tencent_daily()
      └─> 检测规则：6位数字，5开头=上交所，1开头=深交所
          └─> 是ETF → 调用 AkShare Sina
          └─> 不是 → 调用腾讯API

【持久化保存】
  └─> fetch_sector_data.py:_save_etf_to_disk()
      └─> 文件路径：data/etf_daily/etf_${CODE}.jsonl
          格式：{"date":"2026-03-16","open":1.23,"close":1.25,...}

【回补策略】
  └─> 启动时自动执行
      └─> server.js:backfillMissingDataOnStartup()
          └─> 检查缺失日期 → 调用接口补充 → 追加到jsonl文件

【读取优先级】
  1. warmup缓存：data/sector-history-warmup-60.json (优先)
  2. 本地文件：data/etf_daily/etf_${CODE}.jsonl (次选)
  3. 网络请求：实时调用API (兜底)
```

## 四、数据排查流程

### 问题1：成交额分时数据缺失

**症状**：前端显示"无数据"或时间断档

**排查步骤**：
```
1. 检查文件是否存在
   ls data/volume-*.json

2. 检查文件内容
   cat data/volume-20260316.json

3. 检查定时任务是否运行
   搜索 server.js:4952 附近的定时器代码
   确认 isMarketOpenNow() 返回 true

4. 检查数据源
   访问 /api/snapshot 查看 sentiment.volume 是否有值

5. 检查文件权限
   ls -l data/volume-*.json
```

### 问题2：ETF日线数据过期

**症状**：ETF最新日期是几天前

**排查步骤**：
```
1. 检查本地文件最新日期
   tail -1 data/etf_daily/etf_512480.jsonl

2. 检查是否是交易日
   对照交易日历，确认缺失日期是否为周末

3. 手动触发回补
   python3 fetch_sector_data.py etf-daily sh512480

4. 检查启动时回补逻辑
   server.js:backfillMissingDataOnStartup()
```

### 问题3：warmup缓存过期

**症状**：启动时warmup文件日期过旧

**排查步骤**：
```
1. 检查warmup文件日期
   cat data/sector-history-warmup-60.json | grep day

2. 检查更新逻辑
   server.js:updateWarmupIfNeeded()

3. 手动重新生成
   python3 fetch_sector_data.py warmup 60
```

// server.js: 判断当前是否在交易时间
function isMarketOpenNow() {
  const date = new Date();
  const minutes = date.getHours() * 60 + date.getMinutes();

  const morning = minutes >= 570 && minutes <= 690;    // 9:30-11:30
  const afternoon = minutes >= 780 && minutes <= 900;  // 13:00-15:00

  return morning || afternoon;
}
