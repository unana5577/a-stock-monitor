## 2026-03-13

### 7. 止盈止损策略（优先级：高）
- **状态**: 待回测验证
- **背景**: 乖离率用于判断趋势阶段、风险等级、仓位管理指导，但不直接决定止盈止损价格
- **原因**:
  - 乖离率判断的是当前位置（启动/加速/冲刺/顶部）
  - 止盈止损需要考虑买入价格、持仓成本、市场波动等因素
  - 两者目的不同：乖离率用于仓位管理，止盈止损用于风险控制

#### 方案A：基于ATR（真实波动幅度）动态计算

**原理**：
- 计算ATR（Average True Range，真实波动幅度）
- 止损 = 买入价 - 2×ATR
- 止盈 = 买入价 + 3×ATR

**优点**：
- 自适应市场波动
- 高波动品种止损空间大，低波动品种止损空间小
- 专业交易者常用方法

**缺点**：
- 需要计算ATR（14日或20日）
- 2×和3×倍数需要回测验证
- 可能不适合短线（3-5天）操作周期

**待验证**：
- [ ] 计算各ETF的ATR值（14日/20日）
- [ ] 回测2×ATR止损的胜率
- [ ] 回测3×ATR止盈的盈亏比
- [ ] 评估是否适合3-5天操作周期

#### 方案B：固定百分比

**原理**：
- 止损 = 买入价 × (1 - 5%)
- 止盈 = 买入价 × (1 + 8%)

**优点**：
- 简单直接，容易执行
- 不需要复杂计算
- 适合短线操作

**缺点**：
- 无法适应不同ETF的波动特性
- 主线ETF波动大，5%止损可能太紧
- 衰退ETF波动小，8%止盈可能太松

**待验证**：
- [ ] 统计各ETF的3-5日涨跌幅分布
- [ ] 回测-5%/+8%止盈止损的胜率
- [ ] 是否需要根据ETF特性调整百分比？

#### 方案C：基于乖离率回撤

**原理**：
- 止损 = 当前乖离率跌破60%分位
- 止盈 = 当前乖离率突破95%分位

**优点**：
- 与乖离率系统统一
- 自适应各ETF特性
- 考虑趋势阶段

**缺点**：
- 止损/止盈价格不固定，难以提前规划
- 可能与仓位管理策略冲突
- 需要实时监控乖离率分位数

**待验证**：
- [ ] 回测跌破60%分位止损的胜率
- [ ] 回测突破95%分位止盈的盈亏比
- [ ] 评估与仓位管理策略的冲突

#### 下一步计划
1. **立即**：收集数据
   - 计算各ETF的ATR值（14日/20日）
   - 统计各ETF的3-5日涨跌幅分布
   - 计算各ETF的乖离率分位数（60日滚动窗口）

2. **然后**：回测验证
   - 回测方案A：2×ATR止损，3×ATR止盈
   - 回测方案B：-5%止损，+8%止盈
   - 回测方案C：跌破60%分位止损，突破95%分位止盈

3. **最后**：方案选择
   - 对比三种方案的胜率、盈亏比、适用性
   - 选择最优方案或组合方案
   - 集成到主系统
