## 六、授权机制

### 6.1 许可证类型

```json
// license.json 示例
{
  "license_type": "professional",
  "user_id": "xxx",
  "expire_date": "2026-06-10",
  "features": [
    "all_etf",
    "dynamic_threshold",
    "advanced_backtest",
    "realtime_data"
  ],
  "max_users": 1
}
```

### 6.2 验证流程

1. 用户注册 → 生成 license_key
2. 客户端验证 license_key（本地 + 服务器）
3. 获取功能权限列表
4. 定期同步验证（防止篡改）
