## v2.2 阶段0-4 数据要求清单（MVP）

### 阶段0：数据准备
- [ ] 覆盖标的：7个行业ETF（半导体、云计算、新能源、商业航天、创新药、有色金属、通讯设备）
- [ ] 覆盖标的：4个基准指数（上证、深证、创业板、科创50）
- [ ] 覆盖字段：date, open, high, low, close, volume, amount
- [ ] 覆盖范围：起始日期 2025-05-19 起可回溯
- [ ] 全市场成交额：按交易日提供每日总成交额（用于 Amount_Share 分母）
- [ ] 数据落盘：日线可持久化存储（CSV/Parquet/数据库均可），可重复读取与增量追加
- [ ] 更新策略：每日收盘后增量更新（追加当日数据）
- [ ] 非交易日：实时显示用“最近一个交易日”；回测直接跳过非交易日
- [ ] 数据对齐：所有序列按交易日对齐；缺失值仅用于“指标计算中间序列”向前填充，不用于价格/收益口径

### 阶段1：动态基准选择
- [ ] 输入：板块（ETF）60日收盘价 + 4个基准指数60日收盘价
- [ ] 计算：与每个指数的相关系数（皮尔逊）
- [ ] 输出：为每个板块选择一个基准指数 + 相关性数值
- [ ] 重算频率：每月第一个交易日重算一次（窗口为过去60个交易日）
- [ ] 回测冻结：任意交易日T只能用 T-60 到 T-1 的数据计算基准（禁止未来函数）

### 阶段2：三层判断（硬阈值版）
- [ ] 输入：Alpha_5/Alpha_20/Bias_20/Amount_Share/Amount_Share_MA5/Amount_Share_Change 等基础指标
- [ ] 输出：位置、动能、资金行为 三个标签（每日一条）
- [ ] 阈值口径：可先固定阈值跑通逻辑；后续再替换为分位数阈值

### 阶段3：操作建议 + 归因输出
- [ ] 输出：操作建议（如持股/观望/减仓/离场等）
- [ ] 输出：归因文本（能解释“为何给出该建议”，对齐 v2.2 文档口径）
- [ ] 输出：乖离对比（当前偏离与历史极值对照）

### 阶段4：单ETF回测（数据侧前置要求）
- [ ] 历史数据齐全：回测区间内交易日无缺口（或按规则处理缺口）
- [ ] 未来函数防护：所有分位数/极值/基准选择均仅用当日之前数据计算
- [ ] 输出最小结果：信号命中统计、与持有ETF/基准的对照指标
