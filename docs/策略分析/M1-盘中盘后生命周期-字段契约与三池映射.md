## 2) 逻辑目录树（盘后 vs 盘中）

| 模块 | 盘后（v4.0 lifecycle） | 盘中（分时策略 v3.0） |
|---|---|---|
| 目的 | 给第二天与3-5日思路 | 给当下盘中执行信号 |
| 核心输入 | 日线趋势/资金行为/风险（乖离） | 价格水位 + 时间沉淀 + 资金热度（放量/平量/缩量） |
| 核心输出 | 动能(5档) + 资金行为 + 红/绿/黄 + 操作建议 | 盘中状态判断 + 价格空间 + 时间与资金 + 资金热度 |
| 参照项 | 基准指数（只对照，不参与分池） | 不展示“以XX为基准”，只展示盘中证据 |

## 3) 字段契约（盘后 lifecycle.json）

```
lifecycle.json
├─ day
└─ data[]
   ├─ symbol
   ├─ ETF名称
   ├─ 基准指数 / 相关性
   ├─ 动能                  # 5 档标签
   ├─ 资金行为              # 文案标签（放量启动/资金撤退/横盘整理/主线逼空…）
   ├─ 操作建议              # 文案标签（持有/观望/主线持有…）
   ├─ 乖离对比              # 文案字段：当前偏离 +X%，历史极值 +max/-min
   ├─ 归因说明              # 盘后短句（见第6节）
   └─ 指标数据
      ├─ Pct                # 当日涨跌
      ├─ Pct_P80             # 该 ETF 自身 P80 阈值
      ├─ Bias_20
      ├─ Bias_20_History_Max
      ├─ Amount_Share_Pct
      └─ Amount_Share_Change_Pct
```

## 4) 字段契约（盘中 intraday snapshot）

盘中快照输出（与盘后同名字段，复用前端卡片 UI）：

| 字段 | 含义 | 说明 |
|---|---|---|
| `symbol` | ETF代码 | 与盘后一致 |
| `pct` | 今日涨跌幅 | 直接使用 minute.pct；若 minute.pct 为 0 占位则用 price/pre_close 重算 |
| `操作建议` | 盘中状态判断 | 右上角标签（含“待确认”） |
| `动能` | 价格空间 | 强势上涨/正常上涨/横盘/正常下跌/极端下跌（基于本 ETF P80/P10） |
| `资金行为` | 时间与资金 | 例：持久·放量 / 短暂·缩量 |
| `热度占比` | 资金热度 | 仅展示：放量/平量/缩量（不展示量比数值） |
| `归因说明` | 逻辑推演 | 直接使用矩阵 A/B/C 的逻辑推演句 |

说明：
- 盘中池子底色与盘后一致（红/绿/黄）。

## 7) 红/绿/黄 三池定义（盘后为准，盘中沿用）

输入字段（盘后）：
- `动能`
- `指标数据.Bias_20`
- `指标数据.Bias_20_History_Max`

规则：
- 红池：`动能 == 强势向上` 且 `Bias_20 >= 0.9 * Bias_20_History_Max`
- 绿池：`动能 ∈ {强势向上, 偏强向上}` 且不满足红池
- 黄池：其余所有（中性震荡/弱势反弹/弱势向下）
