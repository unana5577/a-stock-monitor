## 6) 红/绿/黄 三池定义（以文档 2.6 为准）

输入字段：
- `动能`
- `指标数据.Bias_20`
- `指标数据.Bias_20_History_Max`

规则：
- 红池：`动能 == 强势向上` 且 `Bias_20 >= 0.9 * Bias_20_History_Max`
  - 主线：在红池基础上，若最近连续 3 个交易日 `Bias_20` 均“创出新的历史上沿”，则定义为主线
- 绿池：`动能 ∈ {强势向上, 偏强向上}` 且不满足红池（风险可控）
- 黄池：其余所有（方向不明/走弱/跌破前低等），对应 `动能 ∈ {中性震荡, 弱势反弹, 弱势向下}`

说明：
- “观望/止盈/减仓”等为操作输出，属于 `操作建议`，不属于三池定义的一部分

## 7) 归因说明（建议新增的两段，用于一一对应）

目的：不新增 UI 栏位，把“中期趋势/拥挤度（风险等级）”写进 `归因说明`，便于排查。

动能说明（盘后动能与 Pct_P80 的关系）：
- `动能 == 强势向上` 的必要条件之一：当日 `指标数据.Pct >= Pct_P80`（Pct_P80 为该 ETF 自身历史涨跌幅的 80 分位阈值）

建议固定格式（追加在现有归因说明中，不替换原句）：

```
中期趋势：{趋势标签(上升趋势/下降趋势/横盘整理)}。
拥挤度：{风险等级(低/中/中高/高)}（基于 Alpha_20 分位 + Amount_Share 分位）。
```
