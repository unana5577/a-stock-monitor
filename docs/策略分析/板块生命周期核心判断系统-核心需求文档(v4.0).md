# 板块生命周期核心判断系统 - 核心需求文档 (v4.0)
补充2026-03-06 第六阶段细节

## 一、系统核心流程

```
市场情绪过滤 → 趋势判断 → 资金行为判断（量能 + K线形态） → 风险等级评估 → 操作建议生成
```

每个步骤的输出作为后续步骤的输入，最终生成可执行的操作建议。

---

## 二、模块详解

### 2.1 市场情绪过滤（顶层过滤器）

**目的**：识别当前市场整体状态，对后续信号进行修正或过滤，避免在极端行情下误判。

**输入**：
- 全市场涨跌家数比（上涨家数/下跌家数，或涨跌比）
- 全市场成交额（两市合计）
- 连板高度（市场最高连板数，可选）

**输出**：市场情绪等级（恐慌、正常、亢奋）

**判断逻辑**（初始规则，可后续优化，暂无涨跌比，先不考虑，后续可以从成交量去替换）：

| 情绪等级 | 触发条件 | 对信号的影响 |
|----------|----------|--------------|
| **恐慌** | 涨跌比 < 0.3（即下跌家数远大于上涨） 或 成交额较前5日均值萎缩20%以上 | 所有买入信号降级（如“积极建仓”降为“轻仓试探”，“轻仓试探”降为“观望”）；卖出信号加强 |
| **亢奋** | 涨跌比 > 2.0 且 成交额较前5日均值放大30%以上 | 所有卖出信号提前（如“分批止盈”可提前），买入信号需警惕 |
| **正常** | 其他情况 | 信号不做调整 |

**注**：情绪过滤仅在极端情况下生效，正常市场不干预信号。

### 2.2 趋势判断

**目的**：确定板块（ETF）当前的中期趋势方向，为后续操作定调。

**输入**：
- 收盘价（close）
- 20日均线（MA20）
- MA20 斜率（过去5日变化）

**输出**：趋势标签（上升趋势、下降趋势、横盘整理）

**判断逻辑**：

```python
def get_trend(ma20, ma20_slope, close):
    """
    趋势判断
    - 上升趋势：MA20斜率 > 0 且 收盘价 > MA20
    - 下降趋势：MA20斜率 < 0 且 收盘价 < MA20
    - 横盘整理：其他情况
    """
    if ma20 is None or ma20_slope is None:
        return "横盘整理"
    
    if ma20_slope > 0 and close > ma20:
        return "上升趋势"
    if ma20_slope < 0 and close < ma20:
        return "下降趋势"
    return "横盘整理"
```

#### 2.2.1 基准盘强势（双趋势）

**目的**：判断“基准盘今天是否强势”，用于解释“共振上涨”与后续动能/分组的策略门控。

**基准盘范围（固定4个，不扩展）**：
- 上证指数：sh000001
- 深证成指：sz399001
- 创业板指：sz399006
- 科创指数：sh000688

**输入**（来自基准指数日线）：
- 收盘价（close）
- 20日均线（MA20）
- MA20 斜率（MA20_slope，过去5日变化）
- 5日均线（MA5）
- MA5 斜率（MA5_slope，过去5日变化）

**输出**：
- 基准中期趋势（上升趋势/下降趋势/横盘整理）
- 基准短期趋势（上升趋势/下降趋势/横盘整理）
- 基准强势（True/False）

**判定定义**：
- 基准中期趋势：复用 2.2 趋势判断（MA20 + MA20_slope + close）
- 基准短期趋势：将 MA20/MA20_slope 替换为 MA5/MA5_slope，得到短期趋势标签
- 基准强势：基准中期趋势为“上升趋势” 且 基准短期趋势为“上升趋势”

### 2.3 资金行为判断（量能 + K线形态）

**目的**：结合成交量和K线形态，识别短期资金动向，输出资金行为标签。

**输入**：
- 成交额（volume）
- 3日均量（volume_ma3）
- 资金热度占比（amount_share = ETF成交额 / 全市场成交额）
- 资金热度占比的3日均值（amount_share_ma3）
- 涨跌幅（pct）
- K线形态（由OHLC计算得出，见2.3.1）
- 趋势标签（来自2.2）
- 近期最高价、最低价（用于横盘突破判断）

**输出**：资金行为标签（放量启动、恐慌出逃、加速赶顶、缩量企稳、放量滞涨、资金撤退、十字星预警、横盘整理等）

#### 2.3.1 K线形态识别函数

```python
def identify_candle(open, high, low, close):
    """
    识别K线形态
    返回：'十字星', '锤子线', '射击之星', '大阳线', '大阴线', '小阳线', '小阴线', '普通K线'
    """
    body = abs(close - open)
    upper = high - max(open, close)
    lower = min(open, close) - low
    total = high - low

    if total == 0:
        return "十字星"
    
    # 十字星：实体很小
    if body / total < 0.1:
        return "十字星"
    
    # 锤子线：下影线长，实体小，上影线短
    if lower > 2 * body and upper < 0.3 * body:
        return "锤子线"
    
    # 射击之星：上影线长，实体小，下影线短
    if upper > 2 * body and lower < 0.3 * body:
        return "射击之星"
    
    # 大阳线/大阴线：实体占比较大
    if body / total > 0.7:
        return "大阳线" if close > open else "大阴线"
    
    # 小阳线/小阴线：实体较小
    if body / total < 0.3:
        return "小阳线" if close > open else "小阴线"
    
    return "普通K线"
```

#### 2.3.2 资金行为判断逻辑（按优先级）

```python
def get_fund_behavior(trend, volume, volume_ma3, amount_share, amount_share_ma3, pct, kline_type, recent_high, recent_low):
    volume_ratio = volume / volume_ma3 if volume_ma3 > 0 else 1.0
    amount_share_ratio = amount_share / amount_share_ma3 if amount_share_ma3 > 0 else 1.0
    
    # ---------- 横盘趋势单独处理 ----------
    if trend == "横盘整理":
        if close > recent_high and (volume_ratio > 1.5 or amount_share_ratio > 1.5):
            return "放量启动"
        if close < recent_low and (volume_ratio > 1.5 or amount_share_ratio > 1.5):
            return "恐慌出逃"
        if volume_ratio < 0.8:
            return "资金撤退"
        return "横盘整理"
    
    # ---------- 上升趋势 ----------
    if trend == "上升趋势":
        # 放量启动
        if pct > 2 and (volume_ratio > 1.3 or amount_share_ratio > 1.3):
            if kline_type in ["大阳线", "中阳线"]:
                return "放量启动"
        
        # 加速赶顶
        if kline_type in ["射击之星", "大阴线"]:
            return "加速赶顶"
        if volume_ratio > 1.3 and pct < 0:
            return "加速赶顶"
        if 0 <= pct < 1 and volume_ratio > 1.2:
            return "加速赶顶"  # 放量滞涨
        
        # 资金撤退
        if volume_ratio < 0.8 and pct < 2:
            return "资金撤退"
        
        # 十字星预警
        if kline_type == "十字星":
            return "十字星预警"
        
        return "正常上升"
    
    # ---------- 下降趋势 ----------
    if trend == "下降趋势":
        # 恐慌出逃
        if pct < -3 and (volume_ratio > 1.5 or amount_share_ratio > 1.5):
            return "恐慌出逃"
        
        # 缩量企稳
        if volume_ratio < 0.7 and pct > -2:
            if kline_type in ["锤子线", "十字星", "小阳线"]:
                return "缩量企稳"
        
        # 十字星预警
        if kline_type == "十字星":
            return "十字星预警"
        
        return "正常下降"
    
    return "未知"
```

**注**：实际实现时需引入 `close` 参数以获取 `recent_high/low`，此处简化。

### 2.4 风险等级评估

**目的**：衡量板块当前的热度和估值压力，用于控制仓位。

**输入**：
- Alpha_20 分位数（过去20日超额收益相对于自身历史的分位，滚动60日窗口）
- Amount_Share 分位数（资金热度占比相对于自身历史的分位，滚动60日窗口）

**输出**：风险等级（低风险、中风险、中高风险、高风险）

**判断逻辑**：

```python
def get_risk_level(alpha20_quantile, amount_share_quantile):
    if alpha20_quantile > 0.8 and amount_share_quantile > 0.8:
        return "高风险"
    elif alpha20_quantile > 0.8:
        return "中高风险"
    elif alpha20_quantile > 0.5:
        return "中风险"
    else:
        return "低风险"
```

**说明**：分位数计算基于过去60日滚动窗口，每日更新。

### 2.6 UI 三池分组（红/绿/黄，v1）

**目的**：把盘后日线 lifecycle 的结果按“趋势×风险”分成 3 个池子，便于 3-5 天交易快速决策。

**原则**：
- 三池分组只使用 lifecycle 的既有字段，不引入新的名词体系
- “观望/止盈/减仓”等属于操作输出（操作建议/资金行为/阶段信号等），不作为三池定义的一部分

**输入字段（来自 lifecycle item）**：
- `动能`：短线方向标签，仅使用：强势向上 / 偏强向上 / 中性震荡 / 弱势反弹 / 弱势向下
- `指标数据.Bias_20`：20 日乖离率，用于衡量“上涨过程中的利润回撤风险”
- `指标数据.Bias_20_History_Max`：Bias_20 的历史上沿（用于对照“接近极值”）

**三池定义（规范版）**：
- 红池：`动能 == 强势向上` 且 `Bias_20 >= 0.9 * Bias_20_History_Max`
  - 主线：在红池基础上，若最近连续 3 个交易日 `Bias_20` 均“创出新的历史上沿”（每日 Bias_20 > 截止前一日的历史上沿），则定义为主线
- 绿池：`动能 ∈ {强势向上, 偏强向上}` 且不满足红池（风险可控）
- 黄池：其余所有（方向不明/走弱/跌破前低等），对应 `动能 ∈ {中性震荡, 弱势反弹, 弱势向下}`

### 2.7 动能（5档，盘后用于3-5日思路）

**目的**：盘后用 5 日趋势 + 量价行为（成交额）输出 5 档动能，用于次日及 3-5 日交易的方向判断。

**输入**：
- 5 日趋势：close 与 MA5、MA5 斜率（MA5_Slope）
- 当日涨跌：Pct（涨/跌）
- 量价行为：
  - 成交额：当日成交额 amount 与前一交易日成交额 amount（放量/缩量）
  - 资金热度：资金热度占比 amount_share 与前一交易日 amount_share（升温/降温）
  - Pct_P80：Pct 在该 ETF 历史分布中的 80 分位阈值（每只 ETF 独立阈值）

**输出**：
- 强势向上 / 偏强向上 / 中性震荡 / 弱势反弹 / 弱势向下

**判定逻辑（与代码保持一致）**：
- 5 日趋势向上（close > MA5 且 MA5_Slope > 0）：
  - 若 Pct >= Pct_P80，则视为“强势上涨日”
  - 强势上涨日：强势向上
  - 其他上涨：偏强向上
  - 下跌：中性震荡
- 5 日趋势向下（close <= MA5 且 MA5_Slope < 0）：
  - 上涨：弱势反弹
  - 下跌：弱势向下
- 其他（趋势不明）：
  - 上涨且（成交额放量 或 资金热度升温）：偏强向上
  - 上涨：中性震荡
  - 下跌：弱势向下

## 三、指标定义与计算

| 指标 | 定义 | 计算方法 |
|------|------|----------|
| MA20 | 20日收盘价均值 | 滚动20日平均 |
| MA20斜率 | MA20的变化率 | (MA20_t - MA20_{t-5}) / 5 |
| 量比 | 当日成交额 / 3日均量 | volume / volume_ma3 |
| 资金热度占比 | ETF成交额 / 全市场成交额 | amount_share |
| 资金热度变化 | 当前资金热度 / 3日均值 - 1 | amount_share / amount_share_ma3 - 1 |
| Alpha_5 | 5日超额收益 | ETF 5日涨幅 - 基准指数5日涨幅（基准动态选择） |
| Alpha_20 | 20日超额收益 | ETF 20日涨幅 - 基准指数20日涨幅 |
| 分位数 | 某指标当前值在过去60日中的排名 | (rank - 1) / (60 - 1) |
| K线形态 | 见2.3.1 | 根据OHLC计算 |
